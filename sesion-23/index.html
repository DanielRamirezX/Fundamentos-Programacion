El tablero del mundo.

En la sesión 22 abriste la segunda dimensión: descubriste que una lista puede contener listas y que, con eso, nace la matriz —filas y columnas, como un tablero de ajedrez o una hoja de cálculo. Hoy aprendemos a habitarla: recorrerla casilla por casilla con dos ciclos for anidados, sumar por fila, por columna y en total, y —para cerrar— darle vida a un tablero de verdad. Hoy el doble for se vuelve un juego.

Esta sesión continúa la 22. Allí viste qué es un arreglo bidimensional; hoy lo indexas y lo recorres. El secreto es uno solo: un for para las filas y, adentro, otro for para las columnas. Desde la sesión 09 el código va en C++ como lenguaje principal, con su equivalente en Python a un clic en la otra pestaña —el puente que ya conoces.

i.

Dos números, una casilla.

En una lista normal, una celda se nombra con un índice: lista[3]. En una matriz hacen falta dos: primero la fila, después la columna. Se escribe tablero[fila][columna] —y, como siempre, se cuenta desde el cero.

Piensa en un edificio: primero eliges el piso (la fila) y luego el departamento (la columna). El primer corchete te lleva a un renglón completo —que es a su vez una lista—; el segundo corchete entra a una celda de ese renglón.

Por eso tablero[0] te devuelve la fila entera, y tablero[0][2] la tercera casilla de esa fila. Asignar es igual de directo: tablero[1][1] = "X" coloca una pieza justo en el centro.

  • El primer índice elige la fila (renglón).
  • El segundo índice elige la columna dentro de esa fila.
  • Si te pasas del límite, Python avisa con un IndexError.
Regla del cuaderno: di siempre fila, columna —en ese orden— y nunca te equivocarás de casilla. La fila es el «¿en qué renglón?»; la columna, el «¿en qué lugar de ese renglón?».
principal · C++
indexar.cpp
// Una matriz 3x3: tres filas, cada una con tres columnas
#include <iostream>
#include <vector>
#include <string>
using namespace std;

int main() {
    vector<vector<string>> tablero = {
        {"X", "O", " "},   // fila 0
        {" ", "X", "O"},   // fila 1
        {" ", " ", "X"},   // fila 2
    };

    // Un solo corchete: la fila entera (es un vector)
    for (string celda : tablero[0])
        cout << "'" << celda << "' ";   // 'X' 'O' ' '
    cout << endl;

    // Dos corchetes: una sola casilla
    cout << tablero[0][2] << endl;     // (espacio)
    cout << tablero[2][2] << endl;     // X

    // Asignar es igual: fila 1, columna 0
    tablero[1][0] = "O";
    for (string celda : tablero[1])
        cout << "'" << celda << "' ";   // 'O' 'X' 'O'
    return 0;
}

ii.

El recorrido del doble for.

Para tocar todas las casillas de una matriz se usan dos ciclos anidados: el de afuera avanza por las filas, y el de adentro, por las columnas de la fila actual. Es el patrón que repetirás toda la vida con datos en dos dimensiones.

Léelo como un lector recorre una página: bajas de renglón en renglón (el for de afuera) y, en cada renglón, lees de izquierda a derecha (el for de adentro). Cuando terminas una fila, vuelves al margen y bajas a la siguiente.

El for exterior toma el número de fila; el interior, el de columna. Con esos dos números entras a cada celda exacta: tablero[fila][columna]. Nueve casillas, recorridas en orden, con apenas seis líneas.

Cuida la sangría: el for de columnas vive dentro del de filas. Si lo sacas un nivel, recorrerás mal el tablero —ese es el error de lógica más típico de hoy.
principal · C++
recorrer.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<vector<int>> tablero = {
        {7, 8, 9},
        {6, 5, 4},
        {3, 2, 1},
    };

    // for de afuera: una fila a la vez
    for (int fila = 0; fila < 3; fila++) {
        // for de adentro: cada columna de esa fila
        for (int columna = 0; columna < 3; columna++) {
            int valor = tablero[fila][columna];
            cout << "[" << fila << "][" << columna
                 << "] = " << valor << endl;
        }
    }
    return 0;
}

// [0][0] = 7   [0][1] = 8   [0][2] = 9
// [1][0] = 6   [1][1] = 5   [1][2] = 4
// [2][0] = 3   [2][1] = 2   [2][2] = 1

iii.

Sumar por fila, por columna, en total.

El mismo doble for, tres lecturas distintas. Imagina una tabla de calificaciones: cada fila es un alumno y cada columna una materia. Sumar por fila te da el desempeño de cada alumno; por columna, el de cada materia.

La clave está en dónde reinicias el acumulador. Para el promedio por alumno (fila), pones suma = 0 al empezar cada fila y recorres sus columnas. Para el promedio por materia (columna), fijas la columna y bajas por todas las filas.

Es el corazón de las hojas de cálculo: cada total de fila o de columna que ves en Excel es, por dentro, exactamente este recorrido. Domínalo aquí y lo reconocerás en todas partes.

  • Por alumno: recorre las columnas de una fila fija.
  • Por materia: recorre las filas de una columna fija.
  • Total: un acumulador único para todas las celdas.
principal · C++
calificaciones.cpp
// filas = alumnos · columnas = materias
#include <iostream>
#include <vector>
#include <string>
#include <iomanip>
using namespace std;

int main() {
    vector<vector<int>> notas = {
        {8, 9, 7},    // Ana
        {6, 10, 8},   // Beto
        {9, 7, 9},    // Caro
    };
    vector<string> nombres = {"Ana", "Beto", "Caro"};

    cout << fixed << setprecision(1);
    // Promedio por alumno (recorre las columnas de su fila)
    for (int fila = 0; fila < 3; fila++) {
        int suma = 0;
        for (int columna = 0; columna < 3; columna++)
            suma += notas[fila][columna];
        double promedio = suma / 3.0;
        cout << nombres[fila] << ": " << promedio << endl;
    }
    return 0;
}

// Ana: 8.0   Beto: 8.0   Caro: 8.3

iv.

Para qué sirve una matriz.

Las matrices no son un capricho académico: son la forma natural de guardar cualquier dato que vive en una cuadrícula. Donde haya filas y columnas, hay una matriz esperando.

Tableros de juego

Ajedrez, gato, buscaminas, Sudoku. Cada casilla es un [fila][columna] —justo lo de hoy.

Hojas de cálculo

Excel y Sheets son matrices gigantes. Los totales por fila y columna son doble for puro.

Imágenes digitales

Una foto es una matriz de píxeles: cada celda guarda un color. Filtrar es recorrerla.

Datos y reportes

Tablas de calificaciones, ventas por mes, censos. Filas y columnas que se suman.

Juego del gato · plano para construir

juego_gato.cpp · 3 funciones · matriz 3×3 · C++ (Python como apoyo)
Descargar el plano (C++) ↓ versión en Python

Dos jugadores se turnan marcando casillas con X y O. El programa valida cada jugada (que la celda esté libre y dentro del tablero) y, tras cada turno, revisa con doble for si alguien completó una línea de tres —en fila, columna o diagonal. Si se llenan las nueve casillas sin ganador, es empate. Usarás todo lo de hoy:

matriz 3×3 tablero[f][c] doble for validación funciones ciclo while
▶ ASÍ SE VERÁ TU JUEGO TERMINADO 0 1 2
+---+---+---+
0 | X | O | |
1 | | X | O |
2 | | | X |
Turno de X — fila: 2 columna: 2
¡Ganó X! Tres en raya (diagonal).

Criterios de evaluación

  1. Sin errores de sintaxis ni de ejecución — el juego corre completo, una partida entera sin reventar.
  2. Lógica correcta — detecta al ganador en filas, columnas y diagonales, y no deja jugar sobre una casilla ocupada.
  3. Funcionamiento óptimo — alterna los dos jugadores, valida el rango del tablero y anuncia victoria o empate.
  4. Autenticidad — código escrito por ti, no copiado de un compañero.
