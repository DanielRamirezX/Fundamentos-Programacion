La gran idea del bimestre: casi cualquier programa útil es una mezcla de pedir un dato, validarlo, decidir y repetir. El examen no pregunta otra cosa: pregunta si dominas esas cuatro acciones. Así se ve, en una sola pieza —en C++ y, en la otra pestaña, en Python:
principal · C++
lo_que_se_evalua.cpp
// Una pieza pequena que toca los cuatro temas del bimestre.
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    const int INTENTOS_MAX = 3;          // constante (sesion 05)
    double suma = 0;
    int aprobados = 0;

    int n;
    cout << "Cuantas calificaciones? ";       // entrada + conversion
    cin >> n;

    for (int i = 1; i <= n; i++) {              // repeticion conocida (for)
        double nota;
        cout << "Nota " << i << ": "; cin >> nota;

        while (nota < 0 || nota > 100) {       // validacion (while + ||)
            cout << "Invalida. Debe ir de 0 a 100." << endl;
            cout << "Nota " << i << ": "; cin >> nota;
        }

        suma = suma + nota;                       // acumulador
        if (nota >= 70) {                        // decision (if/else)
            aprobados = aprobados + 1;          // contador
        }
    }

    double promedio = suma / n;
    cout << fixed << setprecision(2);
    cout << "Promedio: " << promedio
         << " - Aprobados: " << aprobados << " de " << n << endl;
    return 0;
}
lo_que_se_evalua.py
# Una pieza pequeña que toca los cuatro temas del bimestre.
INTENTOS_MAX = 3          # constante (sesión 05)
suma = 0
aprobados = 0

n = int(input("¿Cuántas calificaciones? "))   # entrada + conversión

for i in range(1, n + 1):                    # repetición conocida (for)
    nota = float(input(f"Nota {i}: "))

    while nota < 0 or nota > 100:           # validación (while + or)
        print("Inválida. Debe ir de 0 a 100.")
        nota = float(input(f"Nota {i}: "))

    suma = suma + nota                       # acumulador
    if nota >= 70:                          # decisión (if/else)
        aprobados = aprobados + 1          # contador

promedio = suma / n
print(f"Promedio: {promedio:.2f} — Aprobados: {aprobados} de {n}")

iii.

El pacto de honestidad.

Un examen solo vale lo que vale su honestidad. Aquí no se evalúa al que más sabe copiar, sino al que aprendió a pensar por sí mismo. Este es el acuerdo entre tú y el curso.

INTEGRIDAD ACADÉMICA
El código que entregues debe ser tuyo.
No el más brillante de la sala —el tuyo.

Lo que sostiene tu nota

Tu calificación nace de tu propio trabajo. Copiar de un compañero, dejarte copiar o presentar como tuyo el código de otro anula el reactivo —y, según el reglamento institucional, puede anular el examen completo. La autenticidad es uno de los criterios de evaluación, igual que en cada práctica del bimestre.

Sobre el uso de IA

Durante el bimestre la IA puede ser una maestra que te explica; en el examen no puede ser la mano que escribe. Generar la solución con un asistente (ChatGPT, Copilot, Gemini y similares) está prohibido: lo que se evalúa es tu capacidad de resolver, no la de la máquina. Hoy demuestras lo que tú aprendiste.

Una frontera clara

Aprender con la herramienta es estudiar; entregar lo que la herramienta hizo por ti es engañarte a ti mismo. El día del examen, la única IA permitida eres tú: Inteligencia Auténtica. Confía en ella.

Cómo se califica

  1. Sin errores de sintaxis ni de ejecución — el programa corre completo, sin reventar al ejecutarlo.
  2. Lógica correcta — la solución hace lo que el enunciado pide, también en los bordes y los casos límite.
  3. Funcionamiento óptimo — cumple la validación, la decisión y la repetición que cada problema exige.
  4. Autenticidad — resuelto por ti, sin copiar de un compañero ni generar la respuesta con IA.

Los mismos criterios de siempre

No hay sorpresas: son los cuatro criterios que aplicamos en cada práctica del bimestre. Si ya entregabas con ellos en mente, el examen no cambia nada —solo lo confirma.
