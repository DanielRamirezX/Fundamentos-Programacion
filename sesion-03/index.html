i

Variables y tipos.

Una variable es un nombre que guarda un valor. Su tipo define qué puede hacer.

Imagina una caja con etiqueta. La etiqueta es el nombre de la variable; lo que metes dentro es el valor. En Python no declaras el tipo: él lo deduce según lo que guardes.

  • int — números enteros: 25, -3
  • float — decimales: 1.75, 0.16
  • str — texto, entre comillas: "Carlos"
  • bool — verdadero o falso: True, False
Clave: usa type(variable) para preguntarle a Python de qué tipo es algo. Lo vas a necesitar mucho.
variables.py
# cada variable guarda un valor de cierto tipo
nombre  = "Carlos"      # str
edad    = 25            # int
altura  = 1.75          # float
activo  = True          # bool

print(type(edad))     # <class 'int'>
print(type(altura))   # <class 'float'>
ii

Cadenas (strings).

Texto entre comillas. Se pueden unir, medir, indexar y transformar.

Una cadena es una secuencia de caracteres. Cada carácter tiene una posición (empezando en cero, no en uno). Puedes unirlas con +, contar su longitud con len() y aplicarles métodos como .upper().

  • Concatenar: "Hola" + " " + nombre
  • Longitud: len("Carlos") → 6
  • Indexar: nombre[0] → primer carácter
  • f-strings: f"Hola {nombre}" — la forma moderna
Cuidado: "5" no es 5. El texto no se suma como número — se concatena.
cadenas.py
nombre = "Carlos"

# concatenación e interpolación
saludo = "Hola, " + nombre
moderno = f"Hola, {nombre}!"

print(len(nombre))     # 6
print(nombre[0])      # C
print(nombre.upper())  # CARLOS
iii

Números y operaciones.

Suma, resta, multiplicación, división... y dos que confunden: // y %.

Los operadores aritméticos hacen lo que esperas, con una jerarquía: primero potencias, luego multiplicación y división, al final suma y resta. Igual que en matemáticas. Los paréntesis mandan.

  • / — división normal (da float): 10 / 3 → 3.33…
  • // — división entera: 10 // 3 → 3
  • % — residuo (lo que sobra): 10 % 3 → 1
  • ** — potencia: 2 ** 3 → 8
El truco del %: numero % 2 == 0 te dice si un número es par. Lo vas a usar más de lo que crees.
numeros.py
a = 10
b = 3

print(a + b)    # 13
print(a / b)    # 3.333...
print(a // b)   # 3   (división entera)
print(a % b)    # 1   (residuo)
print(a ** b)   # 1000 (potencia)
iv

Booleanos y condicionales.

Aquí el programa empieza a decidir. La primera bifurcación del camino.

Un booleano solo tiene dos valores: True o False. Surgen de comparar cosas. Y con un if, el programa elige qué hacer según el resultado.

  • Comparar: == (igual), != (distinto), <, >, <=, >=
  • Combinar: and, or, not
  • Decidir: if / elif / else
Ojo: = asigna un valor; == compara. Confundirlos es el error #1 de todo principiante.
condicionales.py
edad = 18

if edad >= 18:
    print("Mayor de edad")
elif edad >= 13:
    print("Adolescente")
else:
    print("Niño")

# imprime: Mayor de edad
v

Funciones y ámbito.

Empaquetar lógica con nombre, para reutilizarla. divide y vencerás.

Una función es un bloque de código con nombre que hace una tarea. Recibe parámetros, hace algo, y puede devolver un resultado con return. Sirve para no repetir código.

  • Definir: def nombre(parametros):
  • Devolver: return entrega el resultado
  • Ámbito: las variables creadas dentro solo viven dentro
print vs return: print muestra en pantalla; return entrega un valor para seguir usándolo. No son lo mismo.
funciones.py
def calcular_iva(precio):
    iva = precio * 0.16
    return precio + iva

total = calcular_iva(480)
print(total)   # 556.8

# 'iva' no existe aquí afuera: era local

print(17 // 5)

¿Por qué? // es división entera: 17 entre 5 cabe 3 veces. % es el residuo: sobran 2.

03condicional
x = 7
if x % 2 == 0:
    print("par")
else:
    print("impar")
Salida
impar

¿Por qué? 7 % 2 da 1 (sobra 1), que no es igual a 0. La condición es falsa, así que entra al else.

04funciones
def doble(n):
    return n * 2

print(doble(doble(3)))
Salida
12

¿Por qué? Primero se evalúa el de adentro: doble(3) = 6. Luego el de afuera: doble(6) = 12.

vi

Dibujar el pensamiento.

El diagrama de flujo: el plano antes de construir. Cada figura tiene un significado.

Antes de escribir código, los programadores dibujan la lógica. Un diagrama de flujo es un mapa visual de cómo «fluye» un programa: por dónde entra, qué calcula, qué decide y por dónde sale. Cada figura significa algo distinto, y aprenderlas es como aprender las señales de tránsito: una vez que las conoces, lees cualquier diagrama del mundo. Vamos a aprenderlas resolviendo un problema real, paso a paso.

El autobús de Bob

Bob es conductor de autobús y se volvió tan popular que a veces no le queda espacio para tantos pasajeros. Quiere un programa que le diga si podrá acomodar a todos los que esperan. Escribiremos una función que recibe tres datos:

cap
Capacidad del autobús (sin contar al conductor).
on
Pasajeros que ya van a bordo.
wait
Personas esperando para subir.

Si hay espacio para todos, la función devuelve 0. Si no, devuelve cuántas personas se quedan sin poder subir.

# ejemplos de uso
cap=10, on=5, wait=5 --> 0 # caben los 5
cap=100, on=60, wait=50 --> 10 # 10 de los 50 no caben
Óvalo
Terminal
Marca el inicio y el fin del programa. Todo diagrama empieza y termina con uno.

Todo diagrama arranca con un óvalo de inicio. En el código, este es el momento en que definimos la función y recibimos los tres datos que Bob nos da. Los parámetros entre paréntesis son nuestra «entrada».

def espacio_autobus(cap, on, wait):
    # aquí empieza nuestra lógica
Rectángulo
Proceso
Representa una acción o cálculo: una asignación, una operación matemática.

El rectángulo es para hacer algo. Aquí calculamos cuántas personas habría en total si todos subieran: las que ya van más las que esperan. Una suma simple guardada en una variable.

    total = on + wait
    # total de personas si todas suben
Rombo
Decisión
Hace una pregunta de sí/no. De él salen dos caminos: uno si es verdadero, otro si es falso.

El rombo es donde el programa decide. Preguntamos: ¿el total de personas cabe en la capacidad? De esta pregunta salen dos caminos. En código, esto es exactamente un if / else.

    if total <= cap:
        # camino "Sí": sí caben todos
    else:
        # camino "No": faltan lugares
Paralelogramo
Entrada / Salida
Representa entrada o salida de datos: leer del usuario, o devolver un resultado.

Cada camino del rombo termina en una salida. Si caben todos, devolvemos 0. Si no, devolvemos cuántos se quedan: el total menos la capacidad. El return entrega ese resultado y termina la función.

    if total <= cap:
        return 0
    else:
        return total - cap

El diagrama completo.

Las piezas, ensambladas. A la izquierda el plano; a la derecha, la traducción exacta a Python.

autobus_bob.py
def espacio_autobus(cap, on, wait):
    # 1. proceso: total de personas
    total = on + wait

    # 2. decisión: ¿caben todos?
    if total <= cap:
        return 0        # sí caben
    else:
        return total - cap  # faltan lugares
espacio_autobus(10, 5, 5) → 0 ✓
espacio_autobus(100, 60, 50) → 10 ✓

El problema

Un elevador de oficinas tiene un límite de personas. Ya hay gente adentro y afuera espera más gente para subir. Escribe una función que diga si caben todos en un solo viaje, o cuántos tendrán que esperar el siguiente. Recibe tres parámetros:

limite

dentro
Personas que ya están adentro.
esperando
Personas esperando para subir.

Si caben todas en un viaje, devuelve 0. Si no, devuelve cuántas deben esperar el siguiente.

# ejemplos de uso
limite=8, dentro=3, esperando=4 --> 0 # caben los 4
limite=6, dentro=4, esperando=5 --> 3 # 3 esperan el siguiente viaje

elevador.py
def espacio_elevador(limite, dentro, esperando):
    # proceso: total de personas
    total = dentro + esperando

    # decisión: ¿caben todas?
    if total <= limite:
        return 0
    else:
        return total - limite

Los tropiezos de todo principiante

Errores que vas a cometer.

No es «si» los cometes, es «cuándo». Todos pasamos por aquí. Reconocerlos antes te ahorra horas de frustración. Si en freeCodeCamp algo no te corre, revisa primero esta lista.

Confundir = con ==

if edad = 18:
if edad == 18:

Uno asigna, el otro compara. Dentro de un if casi siempre quieres comparar.

Olvidar convertir input()

edad = input("Edad: ") total = edad + 1 # error
edad = int(input("Edad: "))

input() siempre da texto. Si vas a hacer matemáticas, convierte con int() o float().

Indentación incorrecta

if x > 0: print("positivo")
if x > 0: print("positivo")

En Python los espacios importan. Lo que está dentro del if va indentado (4 espacios).

Olvidar los dos puntos

if x > 0 print("ok")
if x > 0:

Todo if, else, def termina con dos puntos : antes del bloque.
