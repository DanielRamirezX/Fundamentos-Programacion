¿Compilar o interpretar?

La práctica original habla de «manejo del compilador». Aquí hay una diferencia clave que conviene entender antes de empezar: C se compila, Python se interpreta.

la versión oficial · C

Compilado

CodeBlocks toma todo tu código en C y lo traduce a un programa ejecutable (.exe) antes de correrlo. Si hay un error de sintaxis, no compila: no obtienes programa.

escribir → compilar → ejecutar .exe
nuestra versión · Python

Interpretado

Python no compila. El intérprete lee tu archivo .py y lo ejecuta línea por línea, al instante. En VS Code solo presionas ▶ Run o escribes python archivo.py en la terminal.

escribir → ejecutar (▶)

Mismo resultado en pantalla, distinto camino. Por eso en esta práctica no hablamos de «errores de compilación» sino de errores de sintaxis y de ejecución — los que ya aprendiste a cazar con el debugger.

Salida · print()

La función que «da voz» a tu programa. Todo lo que pongas entre comillas aparece en pantalla. Es el equivalente directo del printf() de la librería stdio.h en C — pero en Python ya está lista, sin incluir nada.

Entrada · input()

Pausa el programa y espera a que el usuario escriba algo. Lo que escribe se guarda como texto; si necesitas un número, recuerda envolverlo con int() — justo el bug que cazamos en la sesión 5.

Comentarios · #

Todo lo que vaya después de # es una nota para humanos que Python ignora al ejecutar. Sirven para explicar tu código — y para escribir tus conclusiones al final, como pide la práctica.

Color · códigos ANSI

Donde C usa windows.h y system(), Python usa unos códigos especiales que la terminal entiende como «pinta esto de tal color». Los guardaremos en constantes para que el código quede legible.

# Guarda los códigos en constantes (¡como en la sesión 6!)
RESET = "\033[0m" # vuelve al color normal
TEXTO_AMARILLO = "\033[33m" # 33 = amarillo
FONDO_AZUL = "\033[44m" # 44 = fondo azul

print(FONDO_AZUL + TEXTO_AMARILLO + " Hola color " + RESET)

¿No se ven los colores en Windows? La terminal de VS Code sí los muestra. Si usas el cmd clásico y salen símbolos raros, instala la librería colorama con pip install colorama y agrega from colorama import init; init() al inicio de tu programa. Eso activa los colores en cualquier terminal de Windows.

Realiza 2 programas que desplieguen en pantalla un letrero o frase de tu preferencia, con las diferencias que se describen en cada caso. La frase es tuya — sé creativo.

Criterios de evaluación

  1. Sin errores de sintaxis ni de ejecución — el programa corre completo sin reventar.
  2. Lógica correcta — hace lo que se pide, sin errores lógicos.
  3. Funcionamiento óptimo — cumple todos los requisitos de cada ejercicio.
  4. Autenticidad — código hecho por ti, no copiado de un compañero.
