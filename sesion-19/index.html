i.

Una función con más manos.

Una función puede recibir varios parámetros, separados por comas. Al llamarla, puedes pasarle los argumentos por posición (en orden) o por nombre (diciendo a cuál pertenecen). Y algunos pueden tener un valor por defecto, para que sean opcionales.

En la sesión 18 una función hacía una cosa con un dato. Pero la vida real pide más contexto: para calcular un precio necesitas el monto y la tasa de impuesto y, quizá, un descuento.

Cada uno de esos datos es un parámetro: una variable que la función espera recibir. Cuando la llamas, lo que le entregas se llama argumento.

  • Por posición: precio(100, 0.16) — el orden manda.
  • Por nombre: precio(monto=100, iva=0.16) — el orden ya no importa y se lee solo.
  • Con valor por defecto: def precio(monto, iva=0.16) — si no pasas iva, vale 0.16.
Regla del cuaderno: los parámetros con valor por defecto van al final de la lista. Primero los obligatorios, después los opcionales. Python lo exige.
precios.py
# iva tiene valor por defecto: es opcional
def precio_final(monto, iva=0.16, descuento=0.0):
    subtotal = monto * (1 - descuento)
    return subtotal * (1 + iva)

# 1) por posicion: monto y, opcional, iva
print(precio_final(100))            # 116.0

# 2) por nombre: el orden ya no importa
print(precio_final(iva=0.08, monto=100))  # 108.0

# 3) los tres datos, con descuento
print(precio_final(100, 0.16, descuento=0.10))  # 104.4
ANATOMÍA DE LA FIRMA
def precio_final(monto, iva=0.16, descuento=0.0):

monto

Parámetro obligatorio. No tiene valor por defecto, así que siempre debes pasarlo al llamar.

iva=0.16

Parámetro con valor por defecto. Si no lo pasas, toma 0.16. Por eso es opcional.

descuento=0.0

Otro opcional. Conviene llamarlo por nombre al usarlo, para que se lea claro qué significa.

ii.

¿Dónde vive una variable?

El alcance (en inglés, scope) es el territorio donde una variable existe. Una variable creada dentro de una función es local: nace al entrar y muere al salir. Afuera, nadie sabe que existió.

Esto, lejos de ser un estorbo, es una bendición: cada función es una habitación cerrada. Lo que ocurre dentro no contamina el resto del programa, y puedes nombrar total o i en dos funciones distintas sin que choquen.

Si una función necesita un dato de afuera, lo correcto es recibirlo como parámetro y devolver el resultado con return —no leer ni escribir variables globales a escondidas.

  • Variable local: definida dentro de la función. Solo vive ahí.
  • Variable global: definida en el cuerpo principal. La función puede leerla, pero conviene evitarlo.
  • Si intentas usar afuera una local, Python lanza un NameError.
Regla del cuaderno: los datos entran por los parámetros y salen por el return. Esa es la puerta. Lo demás, déjalo dentro de la habitación.
alcance.py
def area_circulo(radio):
    # 'resultado' es LOCAL: solo vive aqui
    resultado = 3.1416 * radio ** 2
    return resultado

a = area_circulo(5)
print(a)            # 78.54

# intentar usar la local afuera revienta:
print(resultado)
# NameError: name 'resultado' is not defined
dentro de la función

Variable local

Nace cuando la función arranca y desaparece al terminar. Invisible para el resto del programa. Es tu borrador privado: úsalo sin miedo a ensuciar nada de afuera.

en el cuerpo principal

Variable global

Vive en todo el archivo y la función puede leerla. Pero modificarla desde dentro es fuente de bugs difíciles: mejor recíbela como parámetro y devuelve el cambio con return.

    iv.
    
      
    
        
    El ejercicio del tiempo.
    
        
    Primer ejercicio guiado de hoy: una función que calcula tu edad a partir de tu fecha de nacimiento, usando datetime. Parece trivial —no lo es: hay que recordar si ya cumpliste años este año.
    
      
    
    
    

    
    
      Ejercicio guiado
      
    
        
    
          
    calcular_edad(fecha_nacimiento)
    
          
    Escribe una función que reciba una fecha de nacimiento y devuelva la edad en años cumplidos a día de hoy. El truco: restar los años no basta. Si tu cumpleaños aún no llega este año, tienes un año menos.
    
          
      
            
    • Usa date.today() para la fecha de hoy.
      • 
            
    • Recibe la fecha como parámetro tipo date.
      • 
            
    • Resta los años y corrige con un if si el cumpleaños no ha pasado.
      • 
            
    • Devuelve la edad con return (no la imprimas dentro).
      • 
          
    
        
    
        
    
          
    calcular_edad.py
    

    from datetime import date

def calcular_edad(fecha_nacimiento):
    hoy = date.today()
    edad = hoy.year - fecha_nacimiento.year
    # ¿aún no llega el cumpleaños este año?
    falta_cumple = (hoy.month, hoy.day) < \
        (fecha_nacimiento.month, fecha_nacimiento.day)
    if falta_cumple:
        edad -= 1
    return edad

nacimiento = date(2005, 11, 3)
print(calcular_edad(nacimiento))  # 20

    Dos archivos, una idea
    
        
    Un módulo no es nada exótico: es simplemente un archivo .py con funciones. Cuando otro archivo lo importa, gana todas esas funciones de golpe.
    
        
    El truco de la casa: protege el código de prueba del módulo con if __name__ == "__main__":. Así, al importarlo, no se ejecuta la demostración; solo cuando lo corres directamente.

    mi_estadistica.py · el módulo
    

    # Mi biblioteca de estadistica basica
def promedio(datos):
    return sum(datos) / len(datos)

def maximo(datos):
    return max(datos)

def minimo(datos):
    return min(datos)

def rango(datos):
    return max(datos) - min(datos)

# parametro por defecto: nota minima para aprobar = 6.0
def aprobados(datos, minimo_aprob=6.0):
    return sum(1 for n in datos if n >= minimo_aprob)

# prueba SOLO si corres este archivo
if __name__ == "__main__":
    print(promedio([8, 9, 7]))  # 8.0
    
      
    
      
    
        
    reporte.py · el programa que lo usa
    

    # Importo MI propia biblioteca
import mi_estadistica as est

notas = [8.5, 9.0, 5.5, 7.0, 10.0]

print("=== Reporte del grupo ===")
print(f"Promedio: {est.promedio(notas):.2f}")
print(f"Mayor:    {est.maximo(notas)}")
print(f"Menor:    {est.minimo(notas)}")
print(f"Rango:    {est.rango(notas)}")

# uso el parametro por defecto y luego uno propio
print(f"Aprobados (6.0): {est.aprobados(notas)}")
print(f"Aprobados (8.0): {est.aprobados(notas, 8.0)}")

# === Reporte del grupo ===
# Promedio: 8.00
# Mayor:    10.0
# Menor:    5.5
# Rango:    4.5
# Aprobados (6.0): 4
# Aprobados (8.0): 3
