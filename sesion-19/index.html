El casillero.

Práctica institucional 4 de 4 — la última: estructuras de tipo arreglo. Un arreglo es un casillero: una hilera de cajones numerados, pegados en la memoria, todos del mismo tipo. Hoy llenamos dos. Primero un vector de caracteres donde guardaremos, letra por letra, una frase del usuario. Después una matriz de 3×2 que llenaremos y desplegaremos con ciclos anidados. Vectores y matrices, una dimensión y dos: el mismo casillero, distinto número de llaves.

La práctica se guía en C++, con Python de puente. El practicario oficial pide un programa en lenguaje C con el compilador de CodeBlocks; nosotros lo construiremos en C++ —el lenguaje de cabecera del curso desde la sesión 09— usando VS Code con la extensión de C/C++ (g++/MinGW por debajo). Cada bloque trae dos pestañas: C++ activo y su equivalente en Python a un clic.

i.

Sustento teórico: la colección ordenada.

Un arreglo es una colección finita de elementos homogéneos que se tratan como una unidad: todos del mismo tipo, todos en posiciones contiguas de la memoria RAM (Templeman, 2018). En esta práctica veremos dos: vectores (una dimensión) y matrices (dos).

7.1 · ¿Qué es un arreglo?

colección homogénea

Una fila de cajones numerados desde el 0. Todos guardan el mismo tipo de dato y viven pegados en la memoria. Se accede a cada cajón por su índice: arreglo[3] es el cuarto elemento.

Vector · 1 dimensión

unidimensional

Una sola hilera de casillas. Un texto es un vector de char: cada letra ocupa su casilla, en orden. El Ejercicio 1 guarda ahí una frase completa, carácter por carácter, y luego la recupera entera.

Matriz · 2 dimensiones

bidimensional

Una cuadrícula de renglones y columnas. Se accede con dos índices: matriz[fila][columna]. El Ejercicio 2 llena una de 3×2 y la despliega — con ciclos anidados, como los de la práctica pasada.

Declaración de arreglos (7.2)
principal · C++
declaracion.cpp
// 7.2 · tipo, nombre y tamano entre corchetes
char  frase[100];      // vector: 100 casillas de char
int   numeros[5];      // vector: 5 enteros
int   matriz[3][2];    // matriz: 3 renglones x 2 columnas

// el primer indice siempre es 0:
numeros[0] = 7;         // primera casilla
matriz[2][1] = 9;      // renglon 2, columna 1
declaracion.py
# Python no tiene arreglos fijos: usa listas
frase = list("hola")     # vector de chars: ['h','o','l','a']
numeros = [0] * 5       # vector: 5 casillas en cero
matriz = [[0, 0],       # matriz: lista de listas
          [0, 0],
          [0, 0]]

# el primer indice siempre es 0:
numeros[0] = 7
matriz[2][1] = 9

Los arreglos son la primera estructura de datos del curso: dejamos de guardar un dato suelto por variable y empezamos a guardar colecciones. Todo lo que sabes de ciclos vuelve hoy — porque recorrer un arreglo es, precisamente, un ciclo.

Solución sellada

La lógica de los dos, sin sintaxis.

Si te atoras, aquí está la lógica entera de ambos programas — como diagramas, no como código. Traducirla a C++ sigue siendo tu trabajo, y es justo lo que se evalúa. Ábrela solo después de intentarlo.

Ejercicio 2 · la matriz 3×2 (ciclos anidados)
A · Llenar la matriz
para cada renglón r = 0 … 2 for exterior
para cada columna c = 0 … 1 for interior
pedir un dato → matriz[r][c]
B · Desplegar la matriz
para cada renglón r = 0 … 2 for exterior
para cada columna c = 0 … 1 for interior
mostrar matriz[r][c]
al cerrar el renglón → salto de línea

La matriz no lleva diagrama de flechas: su lógica es un ciclo dentro de otro. El for exterior fija el renglón; el interior recorre sus columnas. Se llena con un par anidado y se despliega con otro — cuatro for en total, dos y dos.

  1. Código y sintaxis sin errores de compilación — g++ compila los dos programas a la primera, sin advertencias ignoradas.
  2. Lógica del programa sin errores lógicos — la frase se recupera entera y la matriz se llena y se despliega correctamente.
