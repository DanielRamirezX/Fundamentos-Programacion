El laberinto fractal.

En la sesión pasada cerramos el juicio del examen y abrimos, apenas, la puerta de los ciclos anidados: un for que vive dentro de otro for. Hoy cruzamos el umbral. Descubriremos que basta repetir una repetición para que aparezcan, como por ensalmo, las tablas, las cuadrículas y los patrones que se dibujan solos. Dos ejes, dos índices, y de pronto todo el plano es nuestro.

Esta sesión continúa la 15. Ya sabes que un ciclo dentro de otro recorre el bucle interior completo por cada vuelta del exterior. Hoy convertimos esa idea en filas y columnas.
El código va en C++ (principal), con Python de apoyo. Desde la sesión 09 adoptamos C++ como lenguaje de cabecera —más cercano al temario de estilo C de UNITEC— y conservamos Python como puente. Cada bloque trae dos pestañas: C++ activo por defecto y su equivalente en Python a un clic. El mismo doble for, dos idiomas.

i.

Un ciclo dentro de otro ciclo.

La regla es de una simpleza implacable: por cada vuelta del ciclo de afuera, el de adentro se ejecuta de principio a fin. Si el exterior da 3 vueltas y el interior 4, el cuerpo más profundo corre 3 × 4 = 12 veces.

Piensa en un reloj. La manecilla de los minutos da una vuelta entera —sus 60 minutos— por cada hora que avanza la manecilla de las horas. El ciclo exterior es la hora; el interior, el minuto. No avanzamos a la siguiente hora hasta que se agotaron todos los minutos.

En código, casi siempre nombramos al índice exterior fila (o i) y al interior columna (o j). El exterior elige en qué renglón estamos; el interior recorre ese renglón de izquierda a derecha, casilla por casilla.

La pregunta de oro: ¿qué se repite por cada repetición? Si la respuesta tiene dos ejes —filas y columnas, horas y minutos, productos y meses— pide a gritos un ciclo anidado.
principal · C++
doble_for.cpp
// Por cada fila, recorremos TODAS sus columnas
#include <iostream>
using namespace std;

int main() {
    for (int fila = 0; fila < 3; fila++) {        // exterior: 0, 1, 2
        for (int columna = 0; columna < 4; columna++) { // interior: 0, 1, 2, 3
            cout << "(" << fila << ", " << columna << ")  ";
        }
        cout << endl;                          // salto de linea al cerrar la fila
    }
    return 0;
}

// Salida:
(0, 0)  (0, 1)  (0, 2)  (0, 3)
(1, 0)  (1, 1)  (1, 2)  (1, 3)
(2, 0)  (2, 1)  (2, 2)  (2, 3)
doble_for.py
# Por cada fila, recorremos TODAS sus columnas
for fila in range(3):          # exterior: 0, 1, 2
    for columna in range(4):   # interior: 0, 1, 2, 3
        print(f"({fila}, {columna})", end="  ")
    print()                  # salto de línea al cerrar la fila

# Salida:
(0, 0)  (0, 1)  (0, 2)  (0, 3)
(1, 0)  (1, 1)  (1, 2)  (1, 3)
(2, 0)  (2, 1)  (2, 2)  (2, 3)

ii.

Tres rostros del mismo laberinto.

El doble for es una sola herramienta, pero se disfraza de tres maneras. Reconocer el disfraz es la mitad de saber resolver el problema (contenido 6.4).

Patrones

dibujar en pantalla

El interior repite un carácter y el exterior controla cuántas veces y en qué renglón. Cuando el límite del interior depende del índice exterior, nacen las pirámides y los triángulos. La forma vive en esa dependencia.

Tablas

filas × columnas

Reportes, calendarios, tablas de multiplicar. El exterior es la fila; el interior, la columna. En cada cruce se calcula o muestra un dato. Es el alma de toda hoja de cálculo y de toda cuadrícula de juego.

Combinaciones

cada uno con cada uno

Emparejar todos los elementos de un conjunto con todos los de otro: tallas con colores, jugadores con rivales, días con horarios. El producto cartesiano hecho código, sin que se escape un solo par.

principal · C++
tabla_multiplicar.cpp
// TABLA: una rejilla de multiplicaciones del 1 al 5
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    const int LIMITE = 5;

    for (int fila = 1; fila <= LIMITE; fila++) {        // renglones 1..5
        for (int columna = 1; columna <= LIMITE; columna++) { // columnas 1..5
            int producto = fila * columna;
            // setw(3) reserva 3 espacios para que la rejilla quede alineada
            cout << setw(3) << producto << " ";
        }
        cout << endl;                          // termina el renglon
    }
    return 0;
}

// Salida (cuadricula perfectamente alineada):
  1   2   3   4   5
  2   4   6   8  10
  3   6   9  12  15
  4   8  12  16  20
  5  10  15  20  25
tabla_multiplicar.py
# TABLA: una rejilla de multiplicaciones del 1 al 5
LIMITE = 5

for fila in range(1, LIMITE + 1):        # renglones 1..5
    for columna in range(1, LIMITE + 1):   # columnas 1..5
        producto = fila * columna
        # :3 reserva 3 espacios para que la rejilla quede alineada
        print(f"{producto:3}", end=" ")
    print()                          # termina el renglón

# Salida (cuadrícula perfectamente alineada):
  1   2   3   4   5
  2   4   6   8  10
  3   6   9  12  15
  4   8  12  16  20
  5  10  15  20  25
iii.

Live coding: la pirámide y el rombo.

Aquí está el truco que lo cambia todo: hacer que el límite del ciclo interior dependa del índice exterior. En cuanto range deja de ser fijo, la cuadrícula se vuelve forma.

principal · C++
piramide.cpp
// PATRON: triangulo de estrellas que crece
#include <iostream>
using namespace std;

int main() {
    const int ALTURA = 5;

    for (int fila = 1; fila <= ALTURA; fila++) {
        // el interior depende de la fila: 1, 2, 3...
        for (int estrella = 0; estrella < fila; estrella++) {
            cout << "*";
        }
        cout << endl;   // baja de renglon
    }
    return 0;
}
piramide.py
# PATRÓN: triángulo de estrellas que crece
ALTURA = 5

for fila in range(1, ALTURA + 1):
    # el interior depende de la fila: 1, 2, 3...
    for estrella in range(fila):
        print("*", end="")
    print()   # baja de renglón

principal · C++
piramide_centrada.cpp
// PATRON: piramide centrada con espacios
#include <iostream>
#include <string>
using namespace std;

int main() {
    const int ALTURA = 5;

    for (int fila = 1; fila <= ALTURA; fila++) {
        int espacios  = ALTURA - fila;     // sangria decreciente
        int estrellas = 2 * fila - 1;    // 1, 3, 5, 7, 9
        // string(n, c) repite el caracter c, n veces
        cout << string(espacios, ' ') << string(estrellas, '*') << endl;
    }
    return 0;
}
piramide_centrada.py
# PATRÓN: pirámide centrada con espacios
ALTURA = 5

for fila in range(1, ALTURA + 1):
    espacios = ALTURA - fila        # sangría decreciente
    estrellas = 2 * fila - 1      # 1, 3, 5, 7, 9
    print(" " * espacios + "*" * estrellas)
Así se verá en la terminal
TERMINAL — piramide_centrada.py

El truco de repetir un carácter —"*" * estrellas en Python, string(estrellas, '*') en C++— a veces ahorra el ciclo interior. Pero entiende primero la versión con doble for: el atajo solo se gana después de dominar el camino largo.

Opción A tabla

Generador de reportes

Una tabla de ventas: por cada producto (fila), muestra sus ventas en cada mes (columna) y el total por producto al final del renglón. El doble for recorre la rejilla; un acumulador suma la fila.

  • Al menos 3 productos y 3 meses
  • Ciclo exterior = producto, interior = mes
  • Acumula y muestra el total por renglón
  • Alinea las columnas con f"{x:5}"

Opción B patrón

El rombo de estrellas

Dibuja un rombo (o un diamante) hecho de estrellas, centrado. Es una pirámide que crece y luego decrece: dos ciclos anidados, uno para la mitad de arriba y otro para la de abajo.

  • Usa una constante ALTURA impar
  • El interior depende de la fila (espacios y estrellas)
  • Mitad ascendente + mitad descendente
  • Debe quedar simétrico al voltearlo

Opción C cuadrícula / combinación

El tablero vacío

Dibuja la cuadrícula de un juego: el tablero del gato (3×3) o un campo de buscaminas (por ejemplo 8×8) con todas sus casillas vacías. El doble for coloca cada celda y traza las líneas.

  • Tamaño en constantes FILAS y COLUMNAS
  • Casillas vacías con . o espacios
  • Separa columnas con | y filas con líneas
  • Extra: numera filas y columnas (combinación de etiquetas)

Importante: entrega un solo caso a tu elección, pero tu código debe contener al menos dos ciclos for anidados y, donde aplique, un acumulador. Pon tus # comentarios explicando qué hace cada ciclo.

Criterios de evaluación

  1. Sin errores de sintaxis ni de ejecución — el programa corre completo sin reventar.
  2. Lógica correcta — la tabla, el patrón o el tablero salen exactamente como se pide.
  3. Funcionamiento óptimo — usa ciclos anidados de verdad y constantes; nada de imprimir línea por línea a mano.
  4. Autenticidad — código hecho por ti, comprendido por ti; no copiado de un compañero.
