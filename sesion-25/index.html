El problema de la amnesia.

Toda variable que has creado vive en la memoria RAM: rapidísima, pero volátil. Cuando el programa termina, esa memoria se libera y tus datos se evaporan. Para conservarlos hay que escribirlos en el disco, que es lento pero permanente.

memoria · RAM

Volátil

Las listas, los diccionarios, las variables del cajero. Viven mientras el programa está corriendo. Cierras la terminal y desaparecen sin dejar rastro: la próxima vez arrancas desde cero.

crear → usar → cerrar → ✗ se borra
disco · archivo

Persistente

Un archivo en el disco duro. Lo que escribes ahí sigue existiendo aunque apagues la computadora. Mañana lo vuelves a abrir y todo está tal como lo dejaste. Eso es persistencia.

escribir → cerrar → ✓ permanece

i.

Abrir con cuidado: with.

Para tocar un archivo necesitas open(): le das el nombre y el modo. Y siempre, siempre, lo envuelves en un with —el que se encarga de cerrarlo por ti, aunque algo salga mal.

Un archivo es como una puerta: se abre, se usa y se cierra. Si olvidas cerrarla, el sistema operativo deja recursos atascados y puedes perder datos a medio escribir. El with resuelve eso: cuando termina su bloque, cierra el archivo automáticamente.

A open() le pasas dos cosas: la ruta del archivo y el modo —si vienes a leer, a escribir o a agregar. Y un detalle de oro en español: el parámetro encoding="utf-8", para que los acentos y las eñes no se rompan.

  • "r" — leer (es el modo por defecto)
  • "w" — escribir desde cero (borra lo anterior)
  • "a" — agregar al final (append)
Regla del cuaderno: nunca uses open() a solas. Escríbelo siempre como with open(...) as f: y deja que Python cierre la puerta por ti.
principal · C++
primer_archivo.cpp
#include <iostream>
#include <fstream>   // ifstream / ofstream
#include <string>
using namespace std;

int main() {
    // ESCRIBIR: ofstream crea o reemplaza el archivo
    ofstream salida("notas.txt");
    salida << "Estudiar para el examen" << endl;
    salida << "Subir la practica a GitHub" << endl;
    salida.close();   // cerramos la puerta

    // LEER: ifstream recorre el archivo renglon a renglon
    ifstream entrada("notas.txt");
    string linea;
    while (getline(entrada, linea)) {
        cout << linea << endl;
    }
    entrada.close();
    return 0;
}

r

read · leer

Abre para leer. Si el archivo no existe, truena con FileNotFoundError.

w

write · escribir

Crea el archivo o lo vacía por completo. Cuidado: lo de antes se pierde.

a

append · agregar

Escribe al final sin borrar nada. Ideal para un diario o un registro.

+

x · exclusivo

Crea el archivo solo si no existe; si ya está, se niega. Útil para no pisar datos.

ii.

Leer línea por línea.

Un archivo de texto es, por dentro, una lista de renglones separados por el carácter de salto de línea \n. Recorrerlo con un for es el pan de cada día —la herencia directa de los ciclos.

Puedes leer todo de un golpe con read(), pero casi siempre querrás ir renglón por renglón. Para eso, un archivo abierto se puede iterar como una lista: cada vuelta del for te entrega una línea.

Cada línea trae pegado su \n del final. Por eso lo limpiamos con .strip(), que recorta espacios y saltos sobrantes. Así guardas el dato desnudo, sin basura.

  • .read() — todo el contenido como un texto
  • .readlines() — una lista de líneas
  • .strip() — quita espacios y \n de los extremos
  • .split(",") — parte una línea por sus comas
Conecta con la 24: cada línea del archivo puede volver a convertirse en un diccionario. Texto en el disco; diccionario en la memoria. Ida y vuelta.
principal · C++
cargar_tareas.cpp
// Cargar las tareas de un .txt a un vector
#include <iostream>
#include <fstream>
#include <vector>
#include <string>
using namespace std;

int main() {
    vector<string> tareas;
    ifstream f("tareas.txt");
    string linea;
    while (getline(f, linea)) {   // getline ya quita el \n
        if (linea != "") {          // ignora vacias
            tareas.push_back(linea);
        }
    }
    f.close();

    cout << "Cargue " << tareas.size() << " tareas." << endl;
    for (int i = 0; i < tareas.size(); i++) {
        cout << i + 1 << ". " << tareas[i] << endl;
    }
    return 0;
}
// Cargue 2 tareas.
// 1. Estudiar para el examen
// 2. Subir la practica a GitHub
cargar_tareas.py
# Cargar las tareas de un .txt a una lista
tareas = []

with open("tareas.txt", "r", encoding="utf-8") as f:
    for linea in f:
        tarea = linea.strip()   # quita el \n
        if tarea != "":           # ignora vacías
            tareas.append(tarea)

print(f"Cargué {len(tareas)} tareas.")
for i, t in enumerate(tareas, 1):
    print(f"{i}. {t}")

iii.

El CSV: una tabla en texto plano.

Cuando un dato tiene varias columnas —tarea, prioridad, hecha— el .txt se queda corto. Entra el .csv: Comma-Separated Values, valores separados por comas. Es lo que abre Excel y Google Sheets, en su forma más honesta.

Cómo lo ves tú (una tabla)

tareaprioridadhecha
Estudiaraltano
Comprar cafébajasí
Llamar a mamámediano

Cómo lo guarda el disco (texto)

tarea,prioridad,hecha
Estudiar,alta,no
Comprar café,baja,sí
Llamar a mamá,media,no

La primera línea son los encabezados; cada coma marca el salto de una columna a la siguiente.

Podrías partir cada línea a mano con .split(",")… pero ¿y si un dato trae una coma dentro? Para eso existe el módulo csv de la biblioteca estándar —el mismo libro que viste en la estantería de la sesión 06—. Él entiende las reglas del formato y no se confunde.

Mi favorito es csv.DictReader: lee cada fila y te la entrega como un diccionario, usando los encabezados como claves. Justo la estructura que dominaste la clase pasada.

Detalle fino: al abrir un CSV se usa newline="" en open(). Es la convención que evita renglones en blanco de más al escribir. Cópialo tal cual.
principal · C++
leer_csv.cpp
#include <iostream>
#include <fstream>
#include <sstream>   // stringstream para partir por comas
#include <string>
using namespace std;

int main() {
    ifstream f("tareas.csv");
    string linea;
    getline(f, linea);   // saltamos los encabezados

    while (getline(f, linea)) {
        stringstream ss(linea);
        string nombre, prio, hecha;
        getline(ss, nombre, ',');   // hasta la 1a coma
        getline(ss, prio, ',');     // hasta la 2a coma
        getline(ss, hecha, ',');
        cout << nombre << " -> " << prio << endl;
    }
    f.close();
    return 0;
}
// Estudiar -> alta
// Comprar cafe -> baja
// Llamar a mama -> media
leer_csv.py
import csv

escribir_csv.cpp
#include <iostream>
#include <fstream>
#include <vector>
#include <string>
using namespace std;

struct Tarea { string nombre; string prioridad; };

int main() {
    vector<Tarea> tareas = {
        { "Estudiar",     "alta" },
        { "Comprar cafe", "baja" },
    };

    ofstream f("tareas.csv");
    f << "tarea,prioridad" << endl;   // los encabezados
    for (Tarea t : tareas) {           // todas las filas
        f << t.nombre << "," << t.prioridad << endl;
    }
    f.close();

    cout << "Guardado en tareas.csv" << endl;
    return 0;
}
escribir_csv.py
import csv

tareas = [
    {"tarea": "Estudiar", "prioridad": "alta"},
    {"tarea": "Comprar café", "prioridad": "baja"},
]

columnas = ["tarea", "prioridad"]
with open("tareas.csv", "w", newline="",
          encoding="utf-8") as f:
    escritor = csv.DictWriter(f, fieldnames=columnas)
    escritor.writeheader()      # los encabezados
    escritor.writerows(tareas)   # todas las filas

print("Guardado en tareas.csv")

Para escribir, su gemelo: csv.DictWriter. Le dices qué columnas quieres (fieldnames), llamas a writeheader() para la primera línea, y luego writerows() vacía toda tu lista de diccionarios de un solo trago.

Fíjate en la simetría: la lista de diccionarios de la sesión 24 entra completa, sin traducir. Esa estructura que diseñaste no fue un capricho —era la antesala del disco.

En clase, Google Colab. Para leer un CSV real sin instalar nada, abriremos un .ipynb en Colab, subiremos un archivo con el botón de carga y lo leeremos con el mismo módulo csv. Misma idea, otra ventana.

iv.

Cuando el archivo no existe.

La primera vez que tu gestor arranca, el archivo de tareas todavía no se ha creado. Pedirle leer algo que no existe lanza un FileNotFoundError y revienta el programa. La cura: try / except.

Anticipar, no rezar.

Un programador profesional no asume que el archivo está ahí: contempla que pueda faltar. El bloque try intenta la lectura; si falla con un FileNotFoundError, el except lo atrapa y, en vez de morir, arranca con la lista vacía.

Es exactamente la mentalidad del debugging de la sesión 05, pero al revés: en vez de cazar el error después, lo prevemos antes. La primera ejecución ya no truena: simplemente empieza limpia.

principal · C++
cargar_tareas.cpp
#include <iostream>
#include <fstream>
#include <vector>
#include <string>
using namespace std;

vector<string> cargar_tareas() {
    vector<string> tareas;
    ifstream f("tareas.txt");
    if (!f.is_open()) {   // primera vez: aun no hay archivo
        cout << "No hay tareas guardadas todavia." << endl;
        return tareas;     // arranca con la lista vacia
    }
    string linea;
    while (getline(f, linea)) {
        if (linea != "") {
            tareas.push_back(linea);
        }
    }
    f.close();
    return tareas;
}
cargar_tareas.py
def cargar_tareas():
    tareas = []
    try:
        with open("tareas.txt", "r",
                  encoding="utf-8") as f:
            for linea in f:
                t = linea.strip()
                if t:
                    tareas.append(t)
    except FileNotFoundError:
        # primera vez: aún no hay archivo
        print("No hay tareas guardadas todavía.")
    return tareas
