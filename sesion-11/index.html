Hasta que…

En la sesión 06 hiciste tu primer juego con un for: un ciclo que cuenta cuántas veces dar la vuelta y se detiene solo. Pero la vida real casi nunca sabe el número de antemano. ¿Cuántas veces preguntarás un dato hasta que el usuario lo teclee bien? Las que hagan falta. Hoy aprendes el ciclo que no cuenta, sino que insiste: el while —repetir hasta que se cumpla una condición.

Desde la sesión 09 el código va en C++ (principal) con su equivalente en Python como apoyo —el mismo razonamiento en dos idiomas. Cada bloque trae dos pestañas: C++ activo por defecto, Python a un clic.

Esta sesión retoma la 06. Allí adivinaste el número con un for de intentos fijos. Hoy lo reescribimos con while para que el juego dure lo que tarde en acertar —y de paso aprendemos a no caer en el temido bucle infinito.

i.

El ciclo que no cuenta.

El while repite un bloque mientras una condición sea verdadera. No sabe cuántas vueltas dará: revisa la condición, y si sigue cierta, vuelve a empezar. Es la repetición condicionante.

Léelo en voz alta y se explica solo: «mientras el café no esté listo, sigue esperando». No cuentas los segundos; revisas una condición una y otra vez hasta que deja de cumplirse.

El secreto de todo while que termina son tres piezas que nunca pueden faltar:

  • Inicialización: antes del ciclo, preparas la variable que vas a vigilar.
  • Condición: la pregunta que se revisa al inicio de cada vuelta.
  • Actualización: dentro del cuerpo, algo cambia para que la condición acabe siendo falsa.

Si te falta la tercera, el ciclo nunca termina. La condición se queda eternamente verdadera y el programa gira para siempre. De eso hablamos en un momento.

Regla del cuaderno: usa for cuando sabes cuántas veces; usa while cuando solo sabes cuándo parar.
principal · C++
cuenta_regresiva.cpp
// 1) Inicializar la variable a vigilar
#include <iostream>
using namespace std;

int main() {
    int segundos = 5;

    // 2) Condicion: mientras sea verdadera, repite
    while (segundos > 0) {
        cout << "Despegue en " << segundos << "..." << endl;
        // 3) Actualizar -> acerca el final
        segundos = segundos - 1;
    }

    cout << "¡Despegue! 🚀" << endl;
    return 0;
}

// Salida:
// Despegue en 5...
// Despegue en 4...
// Despegue en 3...
// Despegue en 2...
// Despegue en 1...
// ¡Despegue! 🚀

ya lo conoces · for

Cuando sabes cuántas veces

El for recorre un rango o una colección conocida. Las vueltas están decididas de antemano: siete intentos, diez alumnos, las letras de una palabra.

  • for i in range(7):
  • «Repite esto exactamente 7 veces.»
  • El contador avanza solo, sin que tú lo toques.
hoy · while

Cuando solo sabes cuándo parar

El while repite mientras algo sea cierto. No hay número fijo: puede dar una vuelta o mil, según lo que pase dentro.

  • while not adivinado:
  • «Sigue hasta que el usuario acierte.»
  • Tú debes asegurar que la condición cambie.
ANATOMÍA DE UN WHILE
┌─ segundos = 5→ inicialización (antes del ciclo)
│  ┌─ ¿segundos > 0?→ condición: se revisa cada vuelta
│  │  ├─ print(...)→ cuerpo: lo que se repite
│  │  └─ segundos -= 1→ actualización: acerca el final
│  └─ cuando es falsa→ sale del ciclo y sigue abajo
└─ print("¡Despegue!")→ después del while

Quita la actualización (la línea segundos -= 1) y la condición jamás será falsa: tienes un bucle infinito.

ii.

El centinela que monta guardia.

A veces no quieres contar, sino leer datos hasta que aparezca una señal de paro. Esa señal —un valor especial que significa «ya terminé»— se llama centinela. Es el guardián que decide cuándo cerrar la puerta.

Imagina que sumas las ventas del día, pero no sabes cuántas hubo. En lugar de preguntar «¿cuántas?», acuerdas una contraseña de salida: cuando el usuario escriba 0, eso significa «no hay más». Ese 0 es el centinela.

El patrón es siempre el mismo, y conviene memorizarlo:

  • Lees una vez antes del ciclo (la «lectura anticipada»).
  • El while se repite mientras el dato no sea el centinela.
  • Dentro, procesas el dato y vuelves a leer el siguiente.

Así, el centinela nunca se procesa: en cuanto aparece, la condición se vuelve falsa y el ciclo se cierra con elegancia.

Elige bien el centinela: debe ser un valor imposible entre los datos reales. Para sumar precios, el 0 sirve; para sumar edades, mejor un -1.
principal · C++
suma_centinela.cpp
// Suma ventas hasta que el usuario escriba 0
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    const double CENTINELA = 0;   // señal de "ya no hay más"
    double total = 0.0, venta;

    // Lectura anticipada: el primer dato
    cout << "Venta (0 para terminar): "; cin >> venta;

    while (venta != CENTINELA) {
        total = total + venta;
        // Leer el SIGUIENTE dato antes de revisar
        cout << "Venta (0 para terminar): "; cin >> venta;
    }

    cout << fixed << setprecision(2);
    cout << "Total del día: $" << total << endl;
    return 0;
}

// El 0 nunca se suma: solo cierra el ciclo.

iii.

Validar hasta que sea correcto.

El uso más cotidiano del while: no dejar avanzar el programa hasta que el usuario teclee algo válido. Si pides una edad y escriben «veinte», no truenas: vuelves a preguntar. Eso es validación robusta.

Un programa frágil confía en que el usuario siempre escribe bien. Uno robusto asume lo contrario: que se equivocará, y prepara una segunda oportunidad. El while es justo esa puerta giratoria —no te deja pasar hasta que el dato cumple las reglas.

Aquí entra una herramienta nueva: el try / except. Si int(texto) no puede convertir lo que escribieron, Python lanzaría un ValueError y el programa moriría. Con try atrapamos ese error y, en lugar de reventar, pedimos el dato de nuevo.

Validar es respetar: un buen programa nunca culpa al usuario por escribir mal. Lo guía, con calma, hasta que escribe bien.
principal · C++
validar_edad.cpp
// Pide una edad válida: entero entre 0 y 120
#include <iostream>
#include <string>
#include <stdexcept>
using namespace std;

int main() {
    int edad = -1;   // -1 = "aún sin edad válida"

    while (edad == -1) {
        cout << "Tu edad: ";
        string texto; cin >> texto;
        int numero;
        try {
            numero = stoi(texto);
        } catch (invalid_argument&) {
            cout << "Eso no es un número. Inténtalo de nuevo." << endl;
            continue;   // vuelve al inicio del while
        }

        if (numero >= 0 && numero <= 120) {
            edad = numero;         // dato válido: rompe la condición
        } else {
            cout << "La edad debe estar entre 0 y 120." << endl;
        }
    }

    cout << "Edad registrada: " << edad << endl;
    return 0;
}
validar_edad.py

Dentro del cuerpo, algo acerca el final. La condición tarde o temprano se vuelve falsa y el ciclo se cierra.

¿Tu programa se quedó atorado? Detenlo con Ctrl+C en la terminal. Luego busca: ¿qué variable de la condición olvidé actualizar?
0

Cero vueltas

Si la condición es falsa desde el inicio, el cuerpo nunca se ejecuta. while False: no imprime nada. A diferencia de otros lenguajes, en Python esto es normal y deseado.

1

Una sola vuelta

El usuario acierta al primer intento; el centinela llega de inmediato. Tu código debe funcionar igual de bien con una iteración que con muchas. Pruébalo siempre.

∞

Muchas (o infinitas)

El caso peligroso. Antes de correr, pregúntate: ¿qué hace que esto termine? Si no puedes señalar la línea que acerca el final, tienes un bucle infinito esperando.

Práctica · en clase

Adivina el número (versión while)

La computadora elige un secreto entre 1 y 100. El jugador intenta una y otra vez; después de cada intento recibe una pista (muy alto / muy bajo). El while sigue hasta que acierta. Compáralo con tu versión for de la sesión 06: ¿cuál se siente más natural para este problema?

  • Usa import random y randint(1, 100)
  • El ciclo: while not adivinado:
  • Valida que el intento sea un número (try / except)
  • Cuenta los intentos y muéstralos al ganar
  • Pista al final: break al acertar es válido

principal · C++
adivina_while.cpp — referencia del profesor
#include <iostream>
#include <string>
#include <stdexcept>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
    // 1) Constantes del juego
    const int NUMERO_MIN = 1;
    const int NUMERO_MAX = 100;

    // 2) La máquina elige su secreto
    srand(time(0));
    int secreto = NUMERO_MIN + rand() % (NUMERO_MAX - NUMERO_MIN + 1);
    int intentos = 0;
    bool adivinado = false;

    cout << "¡Adivina el número entre " << NUMERO_MIN
         << " y " << NUMERO_MAX << "!" << endl;

    // 3) while: repite HASTA QUE el jugador acierte
    while (!adivinado) {
        cout << "Tu intento: ";
        string texto; cin >> texto;

        // 4) Validación robusta: ¿es un número?
        int intento;
        try {
            intento = stoi(texto);
        } catch (invalid_argument&) {
            cout << "Eso no es un número." << endl;
            continue;           // no cuenta como intento
        }

        intentos++;

        // 5) Comparar y dar pista
        if (intento < secreto) {
            cout << "Muy bajo. Inténtalo otra vez." << endl;
        } else if (intento > secreto) {
            cout << "Muy alto. Inténtalo otra vez." << endl;
        } else {
            adivinado = true;   // rompe la condición del while
            cout << "¡Acertaste en " << intentos
                 << " intentos! 🎉" << endl;
        }
    }
    return 0;
}

Validador robusto de entrada

Construye un menú o formulario por consola que no avance hasta recibir datos válidos: un número en un rango, una opción del menú, un «sí/no» bien escrito. Pura validación con while.

Criterios de evaluación

  1. Sin errores de sintaxis ni de ejecución — el programa corre completo y no revienta ni con entradas raras.
  2. Lógica correcta — el while termina cuando debe; nada de bucles infinitos ni de centinelas que se procesan.
  3. Funcionamiento óptimo — valida la entrada de verdad: letras, vacíos y números fuera de rango se manejan con elegancia.
  4. Autenticidad — código escrito por ti, no copiado de un compañero.
