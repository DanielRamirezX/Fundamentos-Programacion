La gran lección: los errores de sintaxis y de ejecución te avisan con un mensaje. Los de lógica (como el #5) no dicen nada — el programa corre, pero miente. Por eso el debugger y mirar las variables valen oro.

i.

Las constantes.

Variables que prometes no cambiar. Una convención entre programadores: si la nombras EN_MAYÚSCULAS, todos saben que nadie la toca.

Python no tiene constantes «de verdad»: nada te impide cambiar un valor. Pero existe una convención universal — si nombras una variable en MAYÚSCULAS con guiones bajos (se llama SCREAMING_SNAKE_CASE), le avisas a todo el mundo: «esto no se modifica».

  • PI = 3.14159
  • IVA_MEXICO = 0.16
  • MAX_INTENTOS = 7

¿Para qué? Para borrar los números mágicos. Si ves total * 0.16 nadie sabe qué es ese 0.16. Si ves total * IVA_MEXICO, el código se explica solo. Y si la tasa cambia, la corriges en un solo lugar.

Regla del cuaderno: si un valor aparece dos veces y nunca cambia, hazlo constante. Lo vas a usar muchísimo en el proyecto de hoy.
constantes.py
# ✗ números mágicos: ¿qué son?
if intentos > 7:
    print("Game over")
premio = puntos * 0.16


# ✓ constantes con nombre claro
MAX_INTENTOS = 7
BONO = 0.16

if intentos > MAX_INTENTOS:
    print("Game over")
premio = puntos * BONO

Las librerías.

Python trae una biblioteca estándar enorme: cientos de módulos ya escritos y probados. Cada uno es un libro con funciones listas para usar — no tienes que reinventarlas. Hoy aprendes a importarlas. Toca cada libro para ver para qué sirve:

    Importar el módulo entero
    
        
    La forma recomendada
    
        
    import random

dado = random.randint(1, 6)  # 1 a 6
    
        
    Llamas a cada cosa con módulo punto función. Queda claro de dónde viene. Así lo usarás hoy en el proyecto.
    
      
    
      
    
        
    Importar solo lo que necesitas
    
        
    Cuando quieres una o dos cosas
    
        
    from random import randint

dado = randint(1, 6)
    
        
    Trae solo randint. Más corto al escribir, pero pierdes la pista visible del módulo de origen.
