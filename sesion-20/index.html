El primer arreglo.

Hasta hoy cada dato vivía en su propia variable: una caja, un nombre, un valor. Eso funciona cuando son tres cosas; se vuelve absurdo cuando son treinta. El arreglo —que en Python llamamos lista— es la respuesta: una sola caja con muchos compartimentos numerados, capaz de guardar todo un grupo de datos relacionados bajo un único nombre. Hoy dejas de nombrar uno por uno y empiezas a pensar en conjuntos.

Esta sesión inaugura el tema 7. Ya dominas variables, decisiones, ciclos y funciones. Hoy le das a tu programa memoria de colección: una estructura que ordena muchos valores en fila.
El código va en C++ (principal), Python como apoyo. Desde la sesión 09 el lenguaje al frente es C++ —más cercano al temario de estilo C de UNITEC— y Python queda como puente, ya conocido. Cada bloque trae dos pestañas: C++ activo por defecto y su equivalente en Python a un clic. En C++, el arreglo de hoy se llama vector.

i.

Una caja con muchos compartimentos.

Un arreglo es una colección ordenada de valores guardados bajo un solo nombre. En Python esa estructura se llama lista: se escribe entre corchetes [ ] y sus elementos se separan con comas.

Pensemos en las calificaciones de un alumno. Con lo que sabías hasta ayer, declararías una variable por cada parcial: cal1, cal2, cal3… Funciona, pero no escala: si mañana son veinte materias, tendrías veinte nombres distintos y veinte líneas casi idénticas.

La lista resuelve eso de raíz. Un solo nombre, calificaciones, contiene todos los valores en orden. La lista recuerda la posición de cada dato y crece o se encoge según lo necesites.

  • Se declara con corchetes: [8, 9, 7].
  • Una lista vacía también es válida: [].
  • Puede guardar números, textos o ambos: ["Ana", 9, True].
Regla del cuaderno: si vas a tener «el dato 1, el dato 2, el dato 3…», no inventes tres variables: declara una lista. Los conjuntos se guardan en colecciones.
principal · C++
declaracion.cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

int main() {
    // Una lista (vector) de calificaciones
    vector<int> calificaciones = {8, 9, 7, 10, 6};

    // Un vector de nombres (textos)
    vector<string> alumnos = {"Ana", "Beto", "Carla"};

    // Un vector vacio, listo para crecer
    vector<int> pendientes;

    for (int c : calificaciones) cout << c << " ";
    cout << endl;
    8 9 7 10 6
    for (string a : alumnos) cout << a << " ";
    cout << endl;
    Ana Beto Carla
    return 0;
}

Un nombre por cada dato

Cada calificación necesita su propia variable. Para promediarlas las escribes todas a mano. Si llegan más, hay que tocar el código en varios lugares.

# 5 datos -> 5 variables
cal1 = 8
cal2 = 9
cal3 = 7
cal4 = 10
cal5 = 6
prom = (cal1+cal2+cal3+cal4+cal5) / 5
hoy · una lista

Un nombre para todos

Una sola variable los contiene a todos. Para sumarlos y contarlos usas funciones que no cambian aunque mañana sean cincuenta datos. El código se vuelve general.

# 5 (o 500) datos -> una lista
cals = [8, 9, 7, 10, 6]
prom = sum(cals) / len(cals)
print(prom)
8.0
ii.

Cada dato tiene su número.

Dentro de la lista, cada elemento ocupa una posición llamada índice. Se accede con corchetes: lista[i]. Y aquí va la primera sorpresa: el conteo empieza en cero, no en uno.

El primer elemento vive en el índice 0, el segundo en el 1, y así sucesivamente. Por eso una lista de cinco elementos tiene índices que van del 0 al 4 —nunca al 5—.

Python añade una elegancia que C no tiene: los índices negativos. El -1 es el último elemento, el -2 el penúltimo. Así llegas al final de la fila sin saber cuántos elementos hay.

También puedes pedir una rebanada —un slice— con lista[inicio:fin]. El inicio se incluye; el fin no. Es como decir «desde aquí, hasta justo antes de allá».

Regla del cuaderno: piensa en el índice como «cuántos pasos doy desde el principio». Desde el primer elemento das cero pasos: por eso es el 0.
principal · C++
indexacion.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> cals = {8, 9, 7, 10, 6};

    // Indices positivos (desde el inicio)
    cout << cals[0] << endl;   // primer elemento
    8
    cout << cals[2] << endl;   // tercer elemento
    7

    // C++ no tiene indices negativos: vamos desde el final
    cout << cals.back() << endl;             // el ultimo
    6
    cout << cals[cals.size() - 2] << endl;   // el penultimo
    10

    // Rebanada: del indice 1 al 3 (el 3 NO entra)
    vector<int> trozo(cals.begin() + 1, cals.begin() + 3);
    for (int x : trozo) cout << x << " ";
    cout << endl;
    9 7
    return 0;
}

Arriba en blanco el índice positivo; en ocre el negativo. cals[0] y cals[-5] apuntan al mismo 8. El último elemento es siempre cals[-1], no importa cuántos haya.

El error que todos cometen: IndexError

Como una lista de cinco llega hasta el índice 4, pedir el cals[5] es salirse del casillero. Python no inventa un valor: detiene el programa con un IndexError.

Es el desbordamiento clásico: querer el «quinto» pensando en el índice 5, cuando el quinto vive en el 4. Para evitarlo, el último índice válido siempre es len(lista) - 1.

Mejor todavía: recorre con un for (lo veremos enseguida) y deja que Python cuide los límites por ti.

cals = [8, 9, 7, 10, 6]
# indices validos: 0, 1, 2, 3, 4

print(cals[5])   # ✗ no existe

Traceback (most recent call last):
  File "indexacion.py", line 4
IndexError: list index out of range

# ✓ el ultimo, sin contar:
print(cals[-1])
6
iii.

Recorrer la fila entera.

Casi nunca tocas un solo elemento: quieres pasar por todos. El for recorre la lista de principio a fin sin que tú lleves la cuenta de los índices. Luego, tres herramientas básicas: append, len y in.

El ciclo for elemento in lista: entrega, uno a uno, cada valor de la lista. No manejas índices, no corres riesgo de IndexError: Python sabe dónde empieza y dónde termina la fila.

Si además necesitas la posición de cada dato —no solo el valor—, enumerate() te entrega ambos: el índice y el elemento, en pareja.

  • for c in cals: recorre los valores.
  • for i, c in enumerate(cals): recorre posición y valor.
  • El cuerpo del for se repite una vez por cada elemento.
Regla del cuaderno: cuando quieras «hacer algo con cada elemento de la lista», la frase ya casi escribe el código: for cada elemento in la lista.
principal · C++
recorrido.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> cals = {8, 9, 7, 10, 6};

    // Recorrer los valores (for-each)
    for (int c : cals)
        cout << "Calificación: " << c << endl;
    Calificación: 8
    Calificación: 9
    Calificación: 7
    Calificación: 10
    Calificación: 6

    // Recorrer posición y valor a la vez (con indice)
    for (int i = 0; i < (int)cals.size(); i++)
        cout << "Parcial " << (i + 1) << ": " << cals[i] << endl;
    Parcial 1: 8
    Parcial 2: 9
    ...
    return 0;
}

lista.append(x)

Agrega un elemento al final. Así crece una lista que empezó vacía.

cals = []
cals.append(8)
cals.append(9)
print(cals)
[8, 9]

len(lista)

Devuelve cuántos elementos hay. Indispensable para promedios y límites.

cals = [8, 9, 7]
print(len(cals))
3
# último índice válido
print(len(cals) - 1)
2

x in lista

Pregunta si un valor está en la lista. Responde True o False.

cals = [8, 9, 7]
print(9 in cals)
True
print(5 in cals)
False

Práctica de la sesión

Estadísticas de una lista

Escribe un programa que parta de una lista de números (calificaciones) y muestre el promedio, el valor máximo y el mínimo. Recorre la lista con un for y usa len() para contar. Pruébalo con varias listas, incluida una de un solo elemento.

  • Declara la lista con al menos 5 calificaciones
  • Calcula la suma recorriendo con for (no uses sum() en esta versión)
  • Obtén el promedio dividiendo entre len(lista)
  • Halla el máximo y el mínimo comparando dentro del ciclo
  • Reto extra: muestra cuántas calificaciones son aprobatorias (>= 6) usando in o una condición

principal · C++
estadisticas.cpp · ejemplo de referencia
// Estadísticas básicas sobre un vector de calificaciones
#include <iostream>
#include <vector>
#include <iomanip>
using namespace std;

int main() {
    vector<int> cals = {8, 9, 7, 10, 6};

    int suma = 0;
    int maxima = cals[0];   // arrancamos con el primero
    int minima = cals[0];
    int aprobadas = 0;

    for (int c : cals) {
        suma = suma + c;
        if (c > maxima) maxima = c;
        if (c < minima) minima = c;
        if (c >= 6) aprobadas = aprobadas + 1;
    }

    double promedio = (double)suma / cals.size();

    cout << "Lista: ";
    for (int c : cals) cout << c << " ";
    cout << endl;
    cout << "Cantidad de datos: " << cals.size() << endl;
    cout << fixed << setprecision(2);
    cout << "Promedio: " << promedio << endl;
    cout << "Máxima: " << maxima << endl;
    cout << "Mínima: " << minima << endl;
    cout << "Aprobatorias: " << aprobadas << " de " << cals.size() << endl;
    return 0;
}
estadisticas.py · ejemplo de referencia
# Estadísticas básicas sobre una lista de calificaciones
cals = [8, 9, 7, 10, 6]

suma   = 0
maxima = cals[0]   # arrancamos con el primero
minima = cals[0]
aprobadas = 0

for c in cals:
    suma = suma + c
    if c > maxima:
        maxima = c
    if c < minima:
        minima = c
    if c >= 6:
        aprobadas = aprobadas + 1

promedio = suma / len(cals)

print(f"Aprobatorias: {aprobadas} de {len(cals)}")

Criterios de evaluación

  1. Sin errores de sintaxis ni de ejecución — el programa corre completo sin reventar (ojo con salirte de los índices: IndexError en Python, fuera de rango en C++).
  2. Lógica correcta — el promedio, la máxima y la mínima son los valores reales de la lista.
  3. Funcionamiento óptimo — el recorrido usa for y el tamaño de la colección (.size() en C++, len() en Python), y funciona aunque cambies la lista.
  4. Autenticidad — código escrito por ti, no copiado de un compañero.
