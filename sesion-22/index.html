i.

Una lista de listas.

Un arreglo bidimensional —una matriz— es, en Python, simplemente una lista cuyos elementos son también listas. Cada lista interior es una fila; cada posición dentro de ella, una columna.

Piensa en una lista normal como un cajón con casillas en fila: [10, 20, 30]. Para llegar a un dato usabas un índice: notas[0].

Una matriz es un archivero: cada cajón guarda, a su vez, otro cajón de casillas. Por eso para llegar a un dato necesitas dos índices: primero qué fila, y luego qué columna dentro de esa fila.

  • tablero[0] te da la primera fila completa (una lista).
  • tablero[0][2] te da la casilla de la fila 0, columna 2.
  • Como en las listas, todo se cuenta desde cero.
Regla del cuaderno: el primer corchete elige la fila; el segundo, la columna. Léelo siempre como matriz[fila][columna].
primera_matriz.py
# Una matriz de 3 filas y 3 columnas
matriz = [
    [1, 2, 3],   # fila 0
    [4, 5, 6],   # fila 1
    [7, 8, 9],   # fila 2
]

# Un solo indice -> una fila entera (lista)
print(matriz[0])        # [1, 2, 3]

# Dos indices -> una sola casilla
print(matriz[0][2])     # 3
print(matriz[2][0])     # 7

# Cuantas filas y cuantas columnas hay
print(len(matriz))       # 3  (filas)
print(len(matriz[0]))    # 3  (columnas)

ii.

Cómo se guarda, cómo se imagina.

La tabla con renglones y columnas vive solo en tu cabeza. En la memoria de la computadora no hay rejillas: hay una lista que contiene, una tras otra, tres listas más pequeñas. La cuadrícula es la metáfora; la lista de listas es la realidad.

en la memoria · la realidad

Una lista que contiene listas

La máquina no sabe de filas ni columnas. Solo guarda una lista grande cuyos tres elementos son, cada uno, una lista chica. La «forma» de tabla la pones tú al leerla con dos índices.

[1, 2, 3] [4, 5, 6] [7, 8, 9]
en tu mente · la metáfora

Una rejilla de filas y columnas

iii.

Tres maneras de declararla.

Declarar una matriz es darle existencia y forma antes de usarla. Según de dónde vengan los datos, hay tres caminos: escribirlos a mano, generarlos vacíos, o llenarlos pidiéndolos al usuario. 7.5 — Declaración de arreglos bidimensionales.

1 · Con valores fijos

# los escribes a mano
tabla = [
    [8, 6, 9],
    [7, 5, 4],
]

La más directa. Sirve cuando ya conoces los datos: un mapa fijo, un calendario, una matriz de ejemplo.

2 · Vacía con un patrón

# 3 filas de 3 ceros, bien hecha
tablero = [[0] * 3
           for _ in range(3)]

Para reservar el espacio antes de saber el contenido. La comprehension de la sesión 21 crea una fila nueva por vuelta.

3 · Llenada por entrada

# el usuario dicta cada valor
fila1 = input("Fila 1: ").split()
fila2 = input("Fila 2: ").split()
datos = [fila1, fila2]

Cuando los datos llegan en tiempo de ejecución. Cada input trae una fila completa que apilas en la lista.

✗ La trampa más famosa
# Parece bien... pero NO lo hagas
tablero = [[0] * 3] * 3

tablero[0][0] = 1
print(tablero)
# [[1, 0, 0], [1, 0, 0], [1, 0, 0]]
# ¡cambiaste UNA y se movieron las TRES!
¿Por qué? El * 3 no crea tres filas: crea tres referencias a la misma fila. Tocar una es tocarlas todas.
✓ La forma correcta
# una fila NUEVA por cada vuelta
tablero = [[0] * 3 for _ in range(3)]

tablero[0][0] = 1
print(tablero)
# [[1, 0, 0], [0, 0, 0], [0, 0, 0]]
# solo se movio la casilla correcta
La diferencia: la comprehension construye una lista independiente en cada iteración. Tres filas, tres objetos distintos.

tablero_gato.py · punto de partida
# =====================================================
# Sesion 22 - Tablero de gato vacio (3x3)
# Fundamentos de Programacion - UNITEC Atizapan 26-3
# =====================================================

FILAS = 3
COLUMNAS = 3
VACIO = " "

# 1) Declaramos la matriz con la forma CORRECTA:
#    una fila nueva e independiente por cada vuelta.
tablero = [[VACIO] * COLUMNAS for _ in range(FILAS)]

# 2) La dibujamos fila por fila.
def dibujar(tab):
    for i in range(len(tab)):
        fila = tab[i]
        # " X | O |   " -> unimos las 3 casillas con barras
        print(f" {fila[0]} | {fila[1]} | {fila[2]} ")
        # linea separadora entre renglones (no tras el ultimo)
        if i < len(tab) - 1:
            print("---+---+---")

dibujar(tablero)

# RETO: ¿como dibujarias un tablero NxN sin escribir
# fila[0], fila[1], fila[2] a mano? Pista: " | ".join(...)

Criterios de evaluación

  1. Sin errores de sintaxis ni de ejecución — el programa corre completo y dibuja el tablero sin reventar.
  2. Lógica correcta — la matriz es realmente 3×3, con filas independientes (nada de la trampa del *).
  3. Funcionamiento óptimo — el tablero se ve alineado, con sus separadores de filas y columnas.
  4. Autenticidad — código escrito por ti, no copiado de un compañero.
