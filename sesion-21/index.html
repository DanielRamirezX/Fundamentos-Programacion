Buscar y ordenar.

En la Práctica 4 levantaste tu primer arreglo: aprendiste a guardar muchos datos en una sola colección, a indexarla y a recorrerla. Pero una colección no sirve de nada si no sabes hallar lo que buscas ni poner orden en ella. Hoy le ponemos músculo a la lista: la recorremos a la caza de un dato, la ordenamos, le quitamos y le añadimos piezas, y descubrimos una forma elegantísima de crearla en una sola línea. Hoy la lista deja de ser un cajón y se vuelve una herramienta.

Esta sesión retoma los arreglos de la Práctica 4. Allí declaraste y recorriste arreglos con indexación y un for. Hoy usamos ese mismo recorrido para buscar, y sumamos los métodos que transforman la lista entera. Desde la sesión 09 el lenguaje principal es C++; cada bloque de código abre en C++ y guarda su equivalente en Python en la otra pestaña, como puente.

i.

La caja de herramientas.

Una lista no es solo un contenedor: trae sus propios métodos, verbos que actúan sobre ella. Hoy sumamos seis a tu vocabulario: sort, reverse, index, count, remove y pop.

Un método se llama con punto: lista.metodo(...). La gran trampa de la que debes cuidarte es ésta: algunos métodos modifican la lista en su sitio y devuelven None; otros te regresan un dato sin tocarla.

  • sort() y reverse() reordenan la lista y devuelven None. Nunca escribas lista = lista.sort() —¡borrarías tu lista!
  • index(x) te dice en qué posición está x; count(x), cuántas veces aparece.
  • remove(x) borra la primera aparición de x; pop(i) saca y te devuelve el de la posición i.
Regla del cuaderno: si un método ordena o vacía, modifica en el sitio. Si te informa algo (posición, cuenta, elemento sacado), te lo devuelve. En la duda, imprímelo y observa.
principal · C++
metodos_lista.cpp
#include <iostream>
#include <vector>
#include <algorithm>   // sort, reverse, find, count
using namespace std;

int main() {
    vector<int> notas = {8, 6, 10, 6, 9};

    sort(notas.begin(), notas.end());     // ordena en el sitio
    // notas -> {6, 6, 8, 9, 10}

    reverse(notas.begin(), notas.end());  // de mayor a menor
    // notas -> {10, 9, 8, 6, 6}

    // index(8): posicion con find + distance
    auto it = find(notas.begin(), notas.end(), 8);
    cout << distance(notas.begin(), it) << endl;  // 2

    // count(6): cuantos seis hay
    cout << count(notas.begin(), notas.end(), 6) << endl; // 2

    // remove(6): borra el PRIMER 6
    notas.erase(find(notas.begin(), notas.end(), 6));

    // pop(0): saca y guarda el de la posicion 0
    int sacada = notas.front();
    notas.erase(notas.begin());
    cout << sacada << endl;            // 10
    return 0;
}
metodos_lista.py

ii.

La búsqueda: a mano y con método.

Buscar es preguntarle a la lista: «¿estás ahí?». Hoy lo hacemos de dos maneras —recorriéndola a pie con un for, y dejando que Python lo haga por ti con in e index().

La búsqueda lineal es la más honesta: empiezas por el principio y revisas elemento por elemento hasta encontrarlo —o hasta agotar la lista. Es exactamente lo que haces tú al buscar una llave en un cajón.

Python ya trae esa misma idea empaquetada: x in lista te responde verdadero o falso, e index(x) te dice dónde está. Pero ojo —index revienta con un ValueError si x no existe. Por eso siempre preguntas primero con in, y solo entonces buscas la posición.

El hábito que salva: if x in lista: antes de lista.index(x). Un buen programa nunca truena porque el dato no estaba.
principal · C++
busqueda.cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>   // find
using namespace std;

int main() {
    vector<string> frutas = {"pera", "uva", "mango", "kiwi"};
    string buscada = "mango";

    // --- Busqueda lineal: a pie, con un for ---
    int posicion = -1;
    for (int i = 0; i < (int)frutas.size(); i++) {
        if (frutas[i] == buscada) {
            posicion = i;
            break;          // ya la hallamos, salimos
        }
    }
    cout << "Lineal: posicion " << posicion << endl; // 2

    // --- La forma de la libreria: find ---
    auto it = find(frutas.begin(), frutas.end(), buscada);
    if (it != frutas.end()) {         // primero pregunto
        cout << "Esta en la posicion "
             << distance(frutas.begin(), it) << endl;
    } else {
        cout << "No esta en la lista" << endl;
    }
    return 0;
}
busqueda.py
frutas = ["pera", "uva", "mango", "kiwi"]
buscada = "mango"

# --- Busqueda lineal: a pie, con un for ---
posicion = -1
for i in range(len(frutas)):
    if frutas[i] == buscada:
        posicion = i
        break          # ya la hallamos, salimos
print(f"Lineal: posicion {posicion}")  # 2

# --- La forma de Python: in + index ---
if buscada in frutas:          # primero pregunto

else:
    print("No esta en la lista")
búsqueda lineal · a mano

Tú recorres, tú decides

Escribes el for con tus manos. Entiendes cada paso y puedes adaptarla: detenerte al primer hallazgo, contar coincidencias o buscar por una condición compleja.

  • Te enseña cómo piensa una búsqueda por dentro.
  • Sirve cuando la condición no es una igualdad simple.
  • Más líneas, pero todo el control es tuyo.
in + index() · de fábrica

Python lo hace por ti

Una línea y listo. Más corto y más legible para el caso común: ¿está este dato exacto?, ¿en qué posición? Lo usarás casi siempre en tu día a día.

  • x in lista responde sí o no.
  • lista.index(x) da la posición.
  • Protégelo: pregunta con in antes, o truena.
iii.

Crear una lista en una línea.

Hay un patrón que repetirás mil veces: «recorre esta lista, quédate con algunos y transfórmalos en una nueva». Python tiene un atajo elegante para eso —la list comprehension.

Hasta hoy, para construir una lista nueva creabas una vacía y la ibas llenando con append() dentro de un for. Funciona, pero son cuatro líneas para una idea muy simple.

Una comprehension dice lo mismo de un tirón, leyéndose casi como español: «el doble de n, para cada n en numeros, si n es par». La condición if del final es opcional: cuando está, filtra; cuando no, transforma todo.

No abuses: la comprehension brilla cuando cabe holgada en una línea. Si la lógica crece o anidas varios for, vuelve al for de toda la vida —se lee mejor.
principal · C++
comprehension.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numeros = {1, 2, 3, 4, 5, 6};

    // C++ no tiene comprehensions: el for + push_back
    // es la forma idiomatica de construir una lista nueva.
    vector<int> pares;
    for (int n : numeros) {
        if (n % 2 == 0) {
            pares.push_back(n * 2);   // filtra y transforma
        }
    }
    for (int x : pares) cout << x << " ";
    cout << endl;                  // 4 8 12

    // sin if: transforma TODOS los elementos
    vector<int> cuadrados;
    for (int n : numeros) cuadrados.push_back(n * n);
    for (int x : cuadrados) cout << x << " ";
    cout << endl;                  // 1 4 9 16 25 36
    return 0;
}
comprehension.py
numeros = [1, 2, 3, 4, 5, 6]

# ANTES: for + lista vacia + append
pares = []
for n in numeros:
    if n % 2 == 0:
        pares.append(n * 2)
print(pares)            # [4, 8, 12]

# DESPUES: la misma idea en una linea
pares = [n * 2 for n in numeros if n % 2 == 0]
print(pares)            # [4, 8, 12]

# sin if: transforma TODOS los elementos
cuadrados = [n ** 2 for n in numeros]
print(cuadrados)        # [1, 4, 9, 16, 25, 36]
ANATOMÍA DE UNA COMPREHENSION
[ n * 2 for n in numeros if n % 2 == 0 ]
n * 2 La salida. Qué guardas de cada elemento: el dato tal cual o transformado.
for n in numeros El recorrido. De dónde sacas cada n, igual que un for normal.
if n % 2 == 0 El filtro (opcional). Solo entran los n que cumplen la condición.

Léela al revés del orden de escritura: primero el for, luego el if, y al final qué guardas. Así verás que dice exactamente lo que haría el bucle largo.

iv.

Caso real: filtrar el inventario.

Live coding en clase. Tenemos una lista de productos con su precio (como pares [nombre, precio]) y un cliente con presupuesto. Queremos quedarnos solo con lo que puede pagar —y verlo ordenado de barato a caro.

Aquí se juntan las tres piezas de hoy. Recorremos el inventario, filtramos con una comprehension según el precio, y después ordenamos el resultado. Nota cómo el sort() usa una clave para decidir por cuál campo ordenar.

Es un patrón que verás en todas partes: filtrar y ordenar una colección de datos. Un catálogo de tienda, una lista de calificaciones, los resultados de una búsqueda —todos viven de esto.

El orden de las operaciones importa: filtra lo que sobra antes de ordenar y trabajarás con menos datos. Primero quitas lo que no cabe en el presupuesto, luego acomodas lo que queda.
principal · C++
inventario.cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>   // sort
using namespace std;

// Cada producto tiene nombre y precio
struct Producto { string nombre; int precio; };

int main() {
    vector<Producto> inventario = {
        {"teclado", 450},
        {"mouse",   220},
        {"monitor", 2800},
        {"cable",   90},
    };
    int presupuesto = 500;

    // 1) Filtrar lo que SI puedo pagar (for + push_back)
    vector<Producto> asequibles;
    for (const Producto& p : inventario) {
        if (p.precio <= presupuesto) asequibles.push_back(p);
    }

    // 2) Ordenar de barato a caro por el precio
    sort(asequibles.begin(), asequibles.end(),
         [](const Producto& a, const Producto& b){ return a.precio < b.precio; });

    cout << "Puedes llevarte:" << endl;
    for (const Producto& p : asequibles) {
        cout << "  " << p.nombre << ": $" << p.precio << endl;
    }
    // Puedes llevarte:
    //   cable: $90
    //   mouse: $220
    //   teclado: $450
    return 0;
}
inventario.py
# Cada producto es [nombre, precio]
inventario = [
    ["teclado", 450],
    ["mouse",   220],
    ["monitor", 2800],
    ["cable",   90],
]
presupuesto = 500

# 1) Filtrar lo que SI puedo pagar (comprehension)
asequibles = [p for p in inventario if p[1] <= presupuesto]

# 2) Ordenar de barato a caro por el precio p[1]
asequibles.sort(key=lambda p: p[1])

print("Puedes llevarte:")
for nombre, precio in asequibles:
    print(f"  {nombre}: ${precio}")
# Puedes llevarte:
#   cable: $90
#   mouse: $220
#   teclado: $450
