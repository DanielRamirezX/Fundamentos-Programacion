6.1 · Los arreglos.

Una variable guarda un dato. Pero un estudiante no aprueba una materia: aprueba diez. Un arreglo es un solo nombre para muchos datos del mismo tipo, numerados por su posición. En lugar de materia1, materia2, materia3… tienes materia[0], materia[1], materia[2].

Piensa en una fila de casilleros pegados: todos del mismo tamaño, todos numerados, y todos bajo un mismo letrero. Ese letrero es el nombre del arreglo; el número del casillero es el índice. Para llegar a cualquiera de ellos no recorres la fila: vas directo, porque conoces su número.

Y de ahí salen sus dos propiedades importantes. Primera: el índice empieza en cero, de modo que un arreglo de tres elementos va del 0 al 2 —nunca al 3—. Segunda: el tamaño se decide al declararlo y ya no cambia. Por eso, cuando no sabes cuántas materias aprobará un alumno, declaras un arreglo con espacio de sobra y llevas aparte una cuenta de cuántos usaste de verdad.

UN ARREGLO · int creditos[3]
[0]
8
[1]
10
[2]
6
[3]
✗

Tres casilleros, del 0 al 2. El casillero [3] no existe: pedirlo es el error más común con arreglos, y C++ no te avisa —simplemente lee basura. Cuenta siempre desde cero.

6.1.1

Definición y propiedades

Muchos datos del mismo tipo bajo un solo nombre. Índice desde 0, tamaño fijo y acceso directo a cualquier posición.

6.1.2

Con un arreglo

Un for que lo recorre de principio a fin y va acumulando: sumar créditos, hallar el mayor, contar cuántos cumplen algo.

6.1.3

Con dos o más

Varios arreglos en paralelo: el mismo índice i apunta al mismo dato en todos. materia[2] vale creditos[2].

6.1.2 · recorrer un arreglo y acumular

principal · C++
un_arreglo.cpp
#include <iostream>
using namespace std;

int main() {
    // UN arreglo: muchos datos, un solo nombre
    int creditos[3] = {8, 10, 6};

    cout << creditos[0] << endl;   // 8  (el primero)
    cout << creditos[2] << endl;   // 6  (el ultimo)

    // recorrido: el for camina por los indices
    int suma = 0;
    for (int i = 0; i < 3; i++) {
        suma = suma + creditos[i];   // acumula
    }
    cout << "Total: " << suma << endl;  // 24
    return 0;
}

6.1.3 · dos o más arreglos en paralelo

principal · C++
dos_arreglos.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // TRES arreglos que caminan juntos:
    // el MISMO indice apunta a la MISMA materia
    string materia[3]  = {"Algebra", "Calculo I", "Estadistica"};
    int    creditos[3] = {8, 10, 6};
    bool   aprobada[3] = {true, true, false};

    int suma = 0;
    for (int i = 0; i < 3; i++) {
        if (aprobada[i]) {            // mismo i en los tres
            cout << materia[i] << " -> "
                 << creditos[i] << endl;
            suma = suma + creditos[i];
        }
    }
    cout << "Aprobados: " << suma << endl;  // 18
    return 0;
}
dos_arreglos.py

El error de una unidad: si el arreglo tiene 3 elementos, el for va de i = 0 mientras i < 3. Nunca i <= 3. Ese «uno de más» es la falla clásica de los arreglos, y en C++ no truena: te da un dato falso.

6.2 · Las cadenas.

Una cadena es texto: el nombre de una materia, el de un alumno, su matrícula. Y aquí está la revelación de hoy: una cadena es también un arreglo —un arreglo de caracteres—. Todo lo que aprendiste arriba se aplica letra por letra.

En C++ tienes dos formas de escribir texto. La clásica, heredada de C, es char nombre[40]: un arreglo de caracteres tal cual. La moderna y cómoda es string, que hace lo mismo pero se encarga sola del tamaño y sabe crecer. Usaremos string, sin olvidar que por dentro sigue siendo una fila de casilleros con letras.

De esa naturaleza doble salen sus tres operaciones básicas: preguntarle su longitud —cuántos caracteres tiene—, indexar —pedir la letra de la posición i— y recorrerla con un for, exactamente como recorriste el arreglo de créditos.

6.2.2 · longitud, indexación y recorrido

principal · C++
cadenas.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string materia = "Calculo I";

    // LONGITUD: cuantos caracteres tiene
    cout << materia.length() << endl;   // 9

    // INDEXACION: la letra de la posicion i
    cout << materia[0] << endl;          // C

    // RECORRIDO: caracter por caracter
    for (int i = 0; i < 9; i++) {
        cout << materia[i] << " ";
    }
    cout << endl;                // C a l c u l o   I
    return 0;
}
cadenas.py

6.3 · Las matrices.

Si el arreglo es una fila de casilleros, la matriz es un edificio de casilleros: renglones y columnas. Se declara con dos corchetes —seriacion[fila][columna]— y se recorre con dos ciclos for, uno dentro del otro.

«UniData» necesita saber qué materias son seriadas: cuáles no puedes cursar hasta aprobar otra. Eso es una relación entre pares de materias, y un arreglo simple no la puede guardar —haría falta un arreglo por cada materia—. La matriz sí: cada renglón es una materia, cada columna es otra materia, y en el cruce ponemos un 1 si la de la columna depende de la del renglón.

Para esta práctica basta con una sola pregunta: «¿qué materia abre cada renglón?». Recorremos un renglón completo a la vez y mostramos las columnas que tienen un 1.

renglón ↓ abre a la columna → ÁlgebraCálculo IEstadística
Álgebra010
Cálculo I001
Estadística000
Todo el plan de estudios en nueve números. El renglón «Álgebra» tiene un 1 en la columna de Cálculo I: aprobar Álgebra abre Cálculo I. Y ése, a su vez, abre Estadística. Estadística no abre ninguna: es el final de la cadena.

6.3.1 · declarar e inicializar la matriz

principal · C++
matriz.cpp
#include <iostream>
#include <string>
using namespace std;

const int PLAN = 3;

int main() {
    string plan[PLAN] = {"Algebra", "Calculo I",
                         "Estadistica"};

    // renglon = materia;  columna = la que DEPENDE
    int seriacion[PLAN][PLAN] = {
        {0, 1, 0},   // Algebra abre Calculo I
        {0, 0, 1},   // Calculo I abre Estadistica
        {0, 0, 0}    // Estadistica no abre nada
    };

    // un dato suelto: renglon 0, columna 1
    cout << seriacion[0][1] << endl;   // 1
    return 0;
}
matriz.py

6.3.2 · recorrerla con dos for anidados

principal · C++
recorridos.cpp
// ¿Que abre cada materia?
// El for de AFUERA recorre los renglones y
// el de ADENTRO, las columnas de ese renglon.

for (int f = 0; f < PLAN; f++) {        // exterior
    cout << plan[f] << " abre: ";

    for (int c = 0; c < PLAN; c++) {    // interior
        if (seriacion[f][c] == 1) {
            cout << plan[c] << " ";
        }
    }
    cout << endl;   // se acabo el renglon
}

Live coding: armamos «UniData».

Ya tenemos las tres piezas sueltas. Ahora las juntamos en un solo sistema, que construimos en vivo, en clase. En esta página queda el plano: los pasos y las firmas, no las respuestas.

Falta un pegamento. Una materia no es un dato: son tres —su nombre, sus créditos y si está aprobada— y los tres viajan juntos. Para eso existe la estructura (struct): un tipo de dato que tú inventas, agrupando varios campos bajo un mismo nombre. A partir de ahí, Materia vale tanto como int o string: puedes declarar una, pasarla a una función… y hacer un arreglo de ellas.

la sintaxis de struct · C++
que_es_un_struct.cpp
// Un ejemplo cualquiera para ver la SINTAXIS.
// Las estructuras de la practica las escribes tu.

struct Libro {        // nombre del nuevo tipo
    string titulo;    // campo 1 (cadena)
    int    paginas;   // campo 2
    bool   leido;     // campo 3
};                    // ← el punto y coma es OBLIGATORIO

int main() {
    Libro l;                      // declarar uno
    l.titulo  = "El Quijote";   // el punto llega al campo
    l.paginas = 863;
    l.leido   = false;

    Libro repisa[10];           // ¡un ARREGLO de structs!
    repisa[0] = l;              // cada casillero, un libro
    cout << repisa[0].titulo << endl;
    return 0;
}
que_es_un_struct.py
# Python no tiene struct: el puente más cercano
# es un DICCIONARIO con los mismos campos.

libro = {
    "titulo":  "El Quijote",   # campo 1 (cadena)
    "paginas": 863,            # campo 2
    "leido":   False           # campo 3
}

print(libro["titulo"])       # los corchetes llegan al campo

repisa = []                  # ¡una LISTA de diccionarios!
repisa.append(libro)        # cada casillero, un libro
print(repisa[0]["titulo"])

Indicación 1 de la práctica: dos estructuras. Una para la materia y otra para el estudiante —y la del estudiante lleva dentro un arreglo de materias. Éste es el mapa que acordamos en clase; la sintaxis la escribes tú.

struct Materia { … };
string nombre El nombre de la materia. Una cadena — puede traer espacios, así que léela con getline.
int creditos Cuántos créditos vale. Es el número que después vas a sumar.
bool aprobado El estado: aprobado o no aprobado. Un bool basta (o un string, si prefieres escribirlo).
struct Estudiante { … };
string nombre El nombre del estudiante. Otra cadena.
string matricula Su número de matrícula. Cadena, no int: puede empezar con cero y no se hacen cuentas con ella.
Materia aprobadas[ ] El arreglo de materias aprobadas. Aquí se juntan las dos estructuras: un arreglo cuyo tipo es tu propia estructura.
int cuantas Cuántas lleva de verdad. El arreglo tiene tamaño fijo; este contador dice hasta dónde está lleno.

Indicaciones 2 y 3: tres funciones sobre ese arreglo. Fíjate en el patrón —las tres recorren lo mismo y cambian solo en qué hacen en cada vuelta: una llena, otra acumula y la tercera cuenta.

indicación 2 · llenar

Ingresar materias

ingresar_materias(Estudiante &e)

Llena el arreglo. Un for que, en cada vuelta, pide nombre, créditos y estado, y los guarda en e.aprobadas[i]. Recibe por referencia: si no, llenaría una copia.

indicación 2 · acumular

Sumar créditos

sumar_creditos(Estudiante e) → int

Recorre y suma. El mismo for, pero acumulando e.aprobadas[i].creditos de las materias aprobadas. Devuelve el total con return.

indicación 3 · contar

Contar materias

contar_materias(Estudiante e) → int

Recorre y cuenta. Cuántas materias tiene el estudiante en su arreglo. Recorrer para contar es el otro uso clásico del ciclo.

Y la matriz, que no se te olvide: la indicación 3 pide además definir la matriz de materias seriadas —renglón = materia, columna = las que dependen de ella— y hacer algo con ella. Con tres materias basta: es una matriz de 3×3, nueve números. Es el criterio de evaluación «operaciones dentro de la matriz»: recórrela con el doble for y muestra el mapa.

arreglo

Un for, tres usos

llenar → e.aprobadas[i] = ... sumar → total = total + creditos contar → total = total + 1

El mismo recorrido con tres finales distintos. Si escribes bien el primero, los otros dos son variaciones de tres líneas.

cadena

getline, no cin

getline(cin, m.nombre); cin.ignore(); ← antes del getline

«Cálculo I» son dos palabras: cin >> se queda con la primera. Usa getline y limpia el enter pendiente con cin.ignore().

matriz

El doble for

for (f...) { for (c...) { } } if (seriacion[f][c] == 1)

El exterior fija el renglón; el interior barre sus columnas. Un salto de línea al cerrar el for exterior y la salida queda acomodada.

Ningún paso es nuevo: el arreglo es la fila de casilleros, la cadena es una fila de letras y la matriz es el doble ciclo anidado que ya usaste en la Práctica 4. Lo único que se agrega hoy es el struct que los mantiene juntos.

Criterios de evaluación

  1. Declaración de las estructuras — las dos estructuras existen, con todos sus campos y con el arreglo de materias dentro del estudiante.

  3. Organización y estructuración — variables con nombre claro, tipos de datos correctos y sintaxis limpia; el programa compila sin errores.
